## 第二章 财务管理基础 ⭐⭐⭐

> 🎯 分值：8-12分 | 题型：全题型（计算必考） | 难度：★★★★☆
> 近年趋势：货币时间价值和风险与收益是后续所有章节的地基，每年必考计算题。

### 一、货币时间价值（核心中的核心！）

**本质**：今天的1块钱 ≠ 明天的1块钱。因为钱可以投资赚取收益。

#### 1.1 复利终值与现值

```
公式1：复利终值 F = P × (1+i)^n     记作：F = P × (F/P, i, n)
公式2：复利现值 P = F × (1+i)^(-n)  记作：P = F × (P/F, i, n)

理解：
  终值 = 现在的钱到未来值多少（往后算）
  现值 = 未来的钱折到现在值多少（往前算）
  两者互为倒数关系：(F/P) × (P/F) = 1
```

#### 1.2 年金终值与现值（⭐⭐⭐高频考点）

| 年金类型 | 含义 | 终值公式 | 现值公式 |
|:---|:---|:---|:---|
| **普通年金** | 每期**末**等额收付 | F = A × (F/A, i, n) | P = A × (P/A, i, n) |
| **预付年金** | 每期**初**等额收付 | F = A × (F/A, i, n) × (1+i) | P = A × (P/A, i, n) × (1+i) |
| **递延年金** | 前m期不付，第m+1期开始 | 同普通年金 | P = A × (P/A, i, n) × (P/F, i, m) |
| **永续年金** | 无限期等额支付 | 无终值 | P = A / i |

> 🔥 **记忆口诀**：
> - 普通年金：期末付，直接查表
> - 预付年金：期初付，比普通年金**多乘一个(1+i)**——因为每笔钱多赚了一期利息
> - 永续年金：P = A/i（无穷等比数列求和的结果）

#### 1.3 利率的计算

```
已知终值/现值/年金，反求利率：
  方法1：查表 + 内插法
  方法2：逐步测试法

内插法公式：
  i = i₁ + (B₁ - B) / (B₁ - B₂) × (i₂ - i₁)

  其中B₁、B₂是查表得到的系数，B是题目给的系数
```

### 📝 实战例题 · 货币时间价值

**题目**：张先生计划5年后买房，届时需要100万元首付。银行年利率4%，他每年年末应存入多少钱？

```
已知：F = 100万，i = 4%，n = 5，求A
F = A × (F/A, 4%, 5)
查表：(F/A, 4%, 5) = 5.4163
A = 100 / 5.4163 = 18.46万元

结论：每年年末存入18.46万，5年后恰好凑够100万首付。
```

### 二、风险与收益

#### 2.1 收益的衡量

```
资产收益率 = 利息/股息收益率 + 资本利得收益率

期望收益率（加权平均）：
  E(R) = Σ Pᵢ × Rᵢ
  （各种可能结果的概率加权平均）
```

#### 2.2 风险的衡量

```
方差：σ² = Σ Pᵢ × (Rᵢ - E(R))²
标准差：σ = √σ²
变异系数：V = σ / E(R)

💡 理解：
  方差/标准差 → 收益波动有多大（绝对风险）
  变异系数 → 每单位收益承担多大风险（相对风险，用于不同方案比较）
```

> 🔥 **比较风险大小**：
> - 期望收益率**相同** → 比标准差（标准差大 = 风险大）
> - 期望收益率**不同** → 比变异系数（变异系数大 = 风险大）

#### 2.3 证券资产组合的风险与收益

```
组合收益率 = 各资产收益率的加权平均

组合风险（两个资产）：
  σp² = W₁²σ₁² + W₂²σ₂² + 2W₁W₂ρ₁₂σ₁σ₂

  ρ₁₂ = 相关系数（-1 ≤ ρ ≤ 1）
  
  ρ = 1 → 完全正相关 → 组合不能降低风险
  ρ = -1 → 完全负相关 → 组合可完全消除风险
  -1 < ρ < 1 → 组合可降低风险但不能完全消除
```

> 💡 **核心结论**：只要两个资产不是完全正相关（ρ < 1），组合就能降低风险。这就是"不要把鸡蛋放在一个篮子里"。

#### 2.4 资本资产定价模型（CAPM）⭐⭐⭐

```
公式（必背！）：
  R = Rf + β × (Rm - Rf)

其中：
  R = 必要收益率
  Rf = 无风险收益率（国债利率）
  β = 系统风险系数
  Rm = 市场平均收益率
  (Rm - Rf) = 市场风险溢酬

💡 理解：
  你投资的必要回报 = 无风险收益 + 风险补偿
  β越大 → 风险越大 → 要求的收益越高
  β = 1 → 风险和市场一样
  β > 1 → 比市场风险大
  β < 1 → 比市场风险小
```

### 📝 实战例题 · CAPM

**题目**：无风险收益率3%，市场平均收益率11%，某股票β = 1.5，求该股票的必要收益率。

```
R = Rf + β × (Rm - Rf)
R = 3% + 1.5 × (11% - 3%)
R = 3% + 1.5 × 8%
R = 3% + 12%
R = 15%

结论：投资该股票至少要求15%的收益率才值得。
```

### 三、成本性态分析

```
总成本 = 固定成本 + 变动成本
Y = a + bX

其中：
  a = 固定成本（不随业务量变化）
  b = 单位变动成本
  X = 业务量

高低点法：
  b = (最高点成本 - 最低点成本) / (最高点业务量 - 最低点业务量)
  a = 最高点成本 - b × 最高点业务量
```

> ⚠️ **高低点的选取**：按**业务量**的最高点和最低点，不是成本的最高和最低！

### 📝 仿真题

**【单选】** 在投资收益率的期望值相同的情况下，标准差越大，表明（ ）。
A. 风险越小  B. 风险越大  C. 无法判断  D. 风险不变

**答案：B** — 期望收益率相同时，标准差（波动）越大 = 风险越大。

**【判断】** 当两项资产收益率的相关系数为0时，投资组合不能降低任何风险。（ ）

**答案：×** — 只要ρ < 1（不是完全正相关），组合就能降低风险。ρ = 0时也能降低。

## 第三章 预算管理 ⭐⭐

> 🎯 分值：5-8分 | 题型：单选、多选、判断、计算 | 难度：★★☆☆☆
> 近年趋势：预算编制方法的选择和经营预算的编制是客观题和计算题的考点。

### 一、预算体系

```
预算体系：
├── 经营预算（日常业务）
│   ├── 销售预算（起点！一切预算的源头）
│   ├── 生产预算（唯一只有数量、没有金额的预算）
│   ├── 直接材料预算
│   ├── 直接人工预算
│   ├── 制造费用预算
│   ├── 产品成本预算
│   └── 销售及管理费用预算
├── 专门决策预算（资本支出预算）
└── 财务预算（终点）
    ├── 现金预算
    ├── 预计利润表
    └── 预计资产负债表
```

> 🔥 **核心链条**：销售预算（起点）→ 生产预算 → 材料/人工/制造费用 → 现金预算 → 预计报表（终点）

### 二、预算编制方法

| 方法 | 传统方法 | 改进方法 | 区别 |
|:---|:---|:---|:---|
| 增量预算 | ✅ | | 以上期为基础+调整 |
| **零基预算** | | ✅ | 一切从零开始，逐项审核 |
| 固定预算 | ✅ | | 只编制一个业务量水平 |
| **弹性预算** | | ✅ | 多个业务量水平，适应性强 |
| 定期预算 | ✅ | | 以会计年度为期间 |
| **滚动预算** | | ✅ | 始终保持12个月，每过1月补1月 |

### 三、经营预算编制（计算重点！）

#### 生产预算

```
预计生产量 = 预计销售量 + 预计期末存货 - 预计期初存货

💡 记忆：生产 = 卖多少 + 想留多少 - 已经有多少
```

#### 直接材料预算

```
预计采购量 = 生产需用量 + 期末存量 - 期初存量
预计采购金额 = 预计采购量 × 单价

现金支出：考虑赊购比例
  当期付现 = 当期采购额 × 当期付款比例 + 上期采购额 × 本期付款比例
```

#### 现金预算

```
可供使用现金 = 期初余额 + 经营现金收入
经营现金支出 = 材料采购 + 人工 + 制造费用 + 销售管理费用 + 所得税
现金余缺 = 可供使用现金 - 经营现金支出
期末余额 = 现金余缺 + 筹资（借款）- 还款 - 利息
```

### 📝 实战例题

**题目**：某公司预计第一季度销售量1000件，第二季度1200件。期末产成品存货量为下季度销售量的10%。期初存货100件。求第一季度生产量。

```
期末存货 = 1200 × 10% = 120件
生产量 = 销售量 + 期末存货 - 期初存货
       = 1000 + 120 - 100 = 1020件
```

### 📝 仿真题

**【单选】** 在编制预算时，以零为起点，对预算期内各项支出的必要性进行逐项审议的方法是（ ）。
A. 增量预算  B. 零基预算  C. 弹性预算  D. 滚动预算

**答案：B** — "以零为起点"+"逐项审议" = 零基预算。

**【判断】** 生产预算是唯一只涉及实物量而不涉及金额的预算。（ ）

**答案：✅** — 生产预算只算生产数量，不算金额。金额在后续的材料、人工预算中体现。

## 第四章 筹资管理（上） ⭐⭐

> 🎯 分值：5-8分 | 题型：全题型 | 难度：★★★☆☆
> 近年趋势：各种筹资方式的优缺点对比、可转换债券是选择题常客。

### 一、筹资方式概览

```
筹资方式：
├── 股权筹资
│   ├── 吸收直接投资
│   ├── 发行普通股
│   └── 留存收益（内部筹资）
├── 债务筹资
│   ├── 银行借款
│   ├── 发行债券
│   ├── 融资租赁
│   └── 商业信用
└── 衍生工具筹资
    ├── 可转换债券
    ├── 认股权证
    └── 优先股
```

### 二、股权筹资

| 方式 | 优点 | 缺点 |
|:---|:---|:---|
| 吸收直接投资 | 手续简便、能引入技术管理 | 资本成本高、产权不易转让 |
| 发行普通股 | 无固定利息、无到期日 | 资本成本最高、控制权分散 |
| 留存收益 | 无发行费用、保持控制权 | 数量有限 |

> 💡 **核心结论**：股权筹资**没有还本压力**，但**成本最高**（股东要求的回报 > 债权人）

### 三、债务筹资

#### 银行借款

| 信用条件 | 含义 | 实际利率影响 |
|:---|:---|:---|
| 补偿性余额 | 借款中留一定比例存在银行 | **实际利率升高** |
| 收款法 | 到期一次还本付息 | 名义利率 = 实际利率 |
| 贴现法 | 借款时先扣利息 | **实际利率升高** |

```
补偿性余额下的实际利率：
  实际利率 = 名义利率 / (1 - 补偿性余额比例)

贴现法的实际利率：
  实际利率 = 名义利率 / (1 - 名义利率)

💡 理解：你能实际用的钱变少了，但利息没变，所以实际利率比名义的高。
```

#### 融资租赁

```
融资租赁的租金计算（等额年金法）：
  每期租金 = 设备价值 / (P/A, i, n)

融资租赁 vs 经营租赁：
  融资租赁：实质取得资产所有权，长期、全额、不可撤销
  经营租赁：只取得使用权，短期、部分、可撤销
```

#### 商业信用

```
放弃现金折扣的成本：
  = 折扣率 / (1 - 折扣率) × 360 / (信用期 - 折扣期)

例如：条件 "2/10, N/30"
  = 2% / (1-2%) × 360 / (30-10)
  = 2.04% × 18
  = 36.73%

💡 理解：放弃2%折扣换来了20天的资金使用权，年化成本高达36.73%！
         所以只要银行利率 < 36.73%，就应该借款享受折扣。
```

### 四、可转换债券 ⭐⭐

```
可转换债券 = 普通债券 + 看涨期权

关键条款：
  转换价格：每股转换时支付的价格
  转换比率 = 债券面值 / 转换价格
  
优点：利率低于普通债券（因为附带了转换权利作为补偿）
缺点：转换后稀释股权、可能丧失低利率优势
```

### 五、优先股

```
优先股特点：
  ✅ 固定股息（类似债券）
  ✅ 优先分配利润和剩余财产（优先于普通股）
  ❌ 一般无表决权
  ❌ 股息不能税前扣除（成本高于债券）

本质：介于债券和普通股之间的"混血"证券
```

### 📝 实战例题

**题目**：某公司按 "2/10, N/30" 的条件购入材料，若放弃折扣，放弃折扣的信用成本率是多少？

```
放弃折扣成本 = 2% / (1-2%) × 360 / (30-10)
             = 2.04% × 18
             = 36.73%

结论：放弃折扣的机会成本高达36.73%，远高于银行贷款利率，应借款享受折扣。
```

### 📝 仿真题

**【单选】** 某公司从银行借款100万元，年利率8%，银行要求补偿性余额20%，该借款的实际利率是（ ）。
A. 8%  B. 10%  C. 12%  D. 6.4%

**答案：B** — 实际利率 = 8% / (1-20%) = 8% / 80% = **10%**

**【多选】** 下列各项中，属于股权筹资方式的有（ ）。
A. 发行普通股  B. 发行优先股  C. 留存收益  D. 融资租赁

**答案：AC** — B优先股属于衍生工具筹资（兼具股债特点）；D融资租赁属于债务筹资。

## 第五章 筹资管理（下） ⭐⭐⭐

> 🎯 分值：10-15分 | 题型：全题型（计算题/综合题必考） | 难度：★★★★☆
> 近年趋势：资本成本计算、杠杆系数、资本结构决策是每年计算题的主战场。

### 一、资本成本（⭐⭐⭐核心公式群）

#### 个别资本成本

| 筹资方式 | 公式 | 要点 |
|:---|:---|:---|
| 银行借款 | Kd = i × (1-T) / (1-f) | 利息可税前扣除，有抵税效应 |
| 债券 | Kb = I × (1-T) / [B₀ × (1-f)] | 同上，注意发行费用 |
| 优先股 | Kp = D / [P₀ × (1-f)] | 股息**不能**税前扣除 |
| 普通股（股利增长模型） | Ks = D₁/P₀ + g | D₁=预期下一年股利，g=增长率 |
| 普通股（CAPM） | Ks = Rf + β(Rm-Rf) | 用资本资产定价模型 |
| 留存收益 | Ke = D₁/P₀ + g | 与普通股相同，但**无发行费用** |

> 🔥 **成本从低到高排序**：银行借款 < 债券 < 优先股 < 留存收益 < 普通股
>
> **记忆口诀**：债务最便宜（有抵税），股权最贵（风险最高）

#### 加权平均资本成本（WACC）

```
WACC = Σ Wⱼ × Kⱼ

即各种筹资方式的资本成本按比例加权平均

💡 权重可以用：账面价值、市场价值、目标价值
   考试通常用市场价值或目标价值
```

### 📝 实战例题 · 资本成本

**题目**：某公司发行面值1000元债券，票面利率8%，发行价950元，发行费率2%，所得税率25%。

```
Kb = 1000 × 8% × (1-25%) / [950 × (1-2%)]
   = 80 × 0.75 / (950 × 0.98)
   = 60 / 931
   = 6.44%
```

### 二、杠杆效应（⭐⭐⭐必考！）

#### 经营杠杆（DOL）

```
DOL = 边际贡献M / 息税前利润EBIT = M / (M - F)

其中：M = 销售收入 - 变动成本
      F = 固定成本

💡 含义：销售量变动1% → EBIT变动DOL%
   固定成本越高 → DOL越大 → 经营风险越大
```

#### 财务杠杆（DFL）

```
DFL = EBIT / [EBIT - I - D/(1-T)]

其中：I = 利息，D = 优先股股利，T = 所得税率

💡 含义：EBIT变动1% → EPS变动DFL%
   负债越多 → 利息越多 → DFL越大 → 财务风险越大
```

#### 总杠杆（DTL）

```
DTL = DOL × DFL = M / [EBIT - I - D/(1-T)]

💡 含义：销售量变动1% → EPS变动DTL%
```

> 🔥 **三种杠杆的本质**：
> - 经营杠杆 → 固定成本放大经营风险
> - 财务杠杆 → 固定利息放大财务风险
> - 总杠杆 → 两者叠加

### 📝 实战例题 · 杠杆系数

**题目**：某公司销售收入500万，变动成本300万，固定成本100万，利息支出40万，无优先股。

```
M = 500 - 300 = 200万
EBIT = 200 - 100 = 100万

DOL = 200 / 100 = 2（销量变10%→EBIT变20%）
DFL = 100 / (100-40) = 1.67（EBIT变10%→EPS变16.7%）
DTL = 2 × 1.67 = 3.33（销量变10%→EPS变33.3%）
```

### 三、资本结构决策

#### 每股收益无差别点法

```
(EBIT* - I₁)(1-T) / N₁ = (EBIT* - I₂)(1-T) / N₂

解出EBIT*，即两种方案EPS相等时的EBIT

决策规则：
  预计EBIT > EBIT* → 选负债多的方案（财务杠杆有利）
  预计EBIT < EBIT* → 选股权多的方案（风险小）
```

### 📝 仿真题

**【单选】** 在其他条件不变的情况下，固定成本增加，经营杠杆系数将（ ）。
A. 增大  B. 减小  C. 不变  D. 不确定

**答案：A** — 固定成本↑ → EBIT↓ → DOL = M/EBIT↑

**【判断】** 总杠杆系数等于经营杠杆系数与财务杠杆系数之和。（ ）

**答案：×** — 是**乘积**不是之和。DTL = DOL × DFL。

## 第六章 投资管理 ⭐⭐⭐

> 🎯 分值：8-12分 | 题型：全题型（计算题必考） | 难度：★★★★☆
> 近年趋势：净现值法、内含报酬率法是计算题常客，项目现金流量的估算也是重点。

### 一、项目现金流量

```
现金流量的构成：
├── 初始期：固定资产投资 + 营运资金垫支 + 旧设备变价收入
├── 营业期：营业现金净流量（NCF）
└── 终结期：回收营运资金 + 回收残值 + 清理费用

营业现金净流量（三个公式，结果相同）：
  公式1：NCF = 营业收入 - 付现成本 - 所得税
  公式2：NCF = 税后净利润 + 折旧（非付现成本）
  公式3：NCF = 收入×(1-T) - 付现成本×(1-T) + 折旧×T ⭐最常用

💡 公式3的精髓：折旧×T = 折旧抵税效应，折旧不花钱但能减税
```

> 🔥 **公式3为什么好用**：它把税后收入、税后成本、折旧抵税三部分分开，计算最清晰。

### 二、投资决策指标

#### 净现值（NPV）⭐⭐⭐

```
NPV = Σ NCFₜ / (1+i)^t - 初始投资

决策规则：
  NPV > 0 → 项目可行（回报率 > 最低要求）
  NPV = 0 → 刚好达到最低要求
  NPV < 0 → 项目不可行

💡 NPV用的折现率 = 必要报酬率（资本成本）
```

#### 内含报酬率（IRR）⭐⭐⭐

```
令 NPV = 0 时的折现率就是IRR

Σ NCFₜ / (1+IRR)^t = 初始投资

求解方法：逐步测试 + 内插法

决策规则：
  IRR > 必要报酬率 → 可行
  IRR < 必要报酬率 → 不可行
```

#### 年金净流量（ANCF）

```
ANCF = NPV / (P/A, i, n)

💡 用途：当两个项目寿命不同时，不能直接比NPV，要用年金净流量比较
```

#### 静态回收期

```
回收期 = 初始投资 / 每年NCF（每年现金流相等时）

每年不等时：逐年累计，找到累计净现金流量由负变正的年份

💡 缺点：没考虑时间价值，也没考虑回收期以后的现金流
```

### 📝 实战例题 · NPV

**题目**：某项目初始投资200万，经营期5年，每年NCF = 60万，折现率10%。(P/A,10%,5) = 3.7908。判断是否可行。

```
NPV = 60 × 3.7908 - 200
    = 227.45 - 200
    = 27.45万 > 0

结论：NPV > 0，项目可行，能创造27.45万的超额价值。
```

### 三、固定资产更新决策

```
核心思路：比较继续使用旧设备 vs 购买新设备的年金成本

年金成本 = 现金流出总现值 / (P/A, i, n)

选年金成本低的方案

⚠️ 注意：旧设备的初始投资 = 变现价值（而非原价或账面价值）
   原理：继续用旧设备 = 放弃了卖掉它的收入 = 机会成本
```

### 📝 仿真题

**【单选】** 下列投资决策指标中，没有考虑货币时间价值的是（ ）。
A. 净现值  B. 内含报酬率  C. 静态回收期  D. 年金净流量

**答案：C** — 静态回收期没有折现，不考虑时间价值。其他三个都用了折现。

**【判断】** 当净现值为零时，说明该投资项目不可行。（ ）

**答案：×** — NPV = 0说明项目回报率恰好等于最低要求（资本成本），**刚好可行**，不是不可行。

## 第七章 营运资金管理 ⭐⭐

> 🎯 分值：5-8分 | 题型：全题型 | 难度：★★★☆☆
> 近年趋势：现金管理模型、应收账款信用政策、经济订货量是计算题高频考点。

### 一、营运资金概述

```
营运资金 = 流动资产 - 流动负债

流动资产投资策略：
  紧缩型：低流动资产，高收益高风险
  宽松型：高流动资产，低收益低风险

流动资产融资策略：
  期限匹配：长期资产用长期资金，短期资产用短期资金
  激进型：用短期资金支撑部分长期资产（风险大、成本低）
  保守型：用长期资金支撑部分短期资产（风险小、成本高）
```

### 二、现金管理

#### 最佳现金持有量——存货模型（鲍莫尔模型）

```
假设：现金均匀消耗，用完一次性补充

总成本 = 交易成本 + 机会成本
       = (T/Q) × F + (Q/2) × K

其中：T = 期间现金需求总量
      Q = 每次转换金额
      F = 每次交易费用
      K = 持有现金的机会成本率

最佳现金持有量：Q* = √(2TF/K)
最低总成本：TC* = √(2TFK)

💡 与存货EOQ公式完全同构！
```

#### 最佳现金持有量——随机模型（米勒-奥尔模型）

```
适用：现金流不确定时

设定三条线：
  上限H、下限L、回归线R

R = ∛(3bσ²/4i) + L
H = 3R - 2L

现金超过H → 买入证券，回到R
现金低于L → 卖出证券，回到R
```

### 三、应收账款管理 ⭐⭐

#### 信用政策决策

```
应收账款机会成本 = 应收账款平均余额 × 变动成本率 × 资本成本率

应收账款平均余额 = 日销售额 × 平均收现期

信用政策决策步骤：
1. 计算各方案的边际贡献
2. 减去机会成本
3. 减去管理费用
4. 减去坏账损失
5. 减去现金折扣成本
6. 比较净收益，选最大的
```

### 📝 实战例题 · 应收账款

**题目**：某公司年赊销额1200万，变动成本率60%，资本成本10%。现行30天收款，拟改为60天以增加销售额到1500万。

```
现行方案：
  机会成本 = (1200/360×30) × 60% × 10% = 100 × 60% × 10% = 6万

新方案：
  机会成本 = (1500/360×60) × 60% × 10% = 250 × 60% × 10% = 15万

增加的机会成本 = 15 - 6 = 9万
增加的边际贡献 = (1500-1200) × (1-60%) = 300 × 40% = 120万

120万 > 9万 → 信用放宽有利（还需考虑坏账变化）
```

### 四、存货管理 ⭐⭐

#### 经济订货量（EOQ）

```
公式（必背！）：
  Q* = √(2KD/Kc)

其中：
  K = 每次订货成本
  D = 年需求量
  Kc = 单位储存成本

最佳订货次数 = D / Q*
最低总成本 = √(2KDKc)

💡 EOQ使得订货成本 = 储存成本（两者相等时总成本最低）
```

#### 再订货点

```
再订货点 = 平均交货期内的需求量 + 保险储备
         = 日需求量 × 交货天数 + 保险储备
```

### 📝 仿真题

**【单选】** 在经济订货量模型中，随着每次订货批量的增加（ ）。
A. 订货成本增加  B. 储存成本减少  C. 订货成本减少  D. 总成本减少

**答案：C** — 每次订货量大→订货次数少→订货成本减少（但储存成本增加）。

**【判断】** 采用存货模型确定最佳现金持有量时，最佳持有量是使交易成本等于机会成本时的现金持有量。（ ）

**答案：✅** — 与EOQ原理相同，两种成本相等时总成本最低。

## 第八章 成本管理 ⭐⭐⭐

> 🎯 分值：8-12分 | 题型：全题型（计算题/综合题高频） | 难度：★★★★☆
> 近年趋势：本量利分析（保本点、保利点）和标准成本差异分析是必考计算题。

### 一、本量利分析（⭐⭐⭐核心！）

#### 基本公式

```
利润 = 销售收入 - 变动成本 - 固定成本
     = 单价×销量 - 单位变动成本×销量 - 固定成本
     = (单价 - 单位变动成本) × 销量 - 固定成本
     = 单位边际贡献 × 销量 - 固定成本

边际贡献率 = 边际贡献 / 销售收入 = 1 - 变动成本率
```

#### 保本分析

```
保本点销售量 = 固定成本 / 单位边际贡献
保本点销售额 = 固定成本 / 边际贡献率

💡 保本 = 利润为零，刚好不亏不赚
```

#### 保利分析

```
保利点销售量 = (固定成本 + 目标利润) / 单位边际贡献
保利点销售额 = (固定成本 + 目标利润) / 边际贡献率

💡 保利 = 达到目标利润需要的销售量/额
```

#### 安全边际

```
安全边际量 = 实际(预计)销售量 - 保本点销售量
安全边际率 = 安全边际量 / 实际(预计)销售量

利润 = 安全边际量 × 单位边际贡献
     = 安全边际额 × 边际贡献率

安全边际率判断标准：
  ≥40% 很安全 | 30%-40% 安全 | 20%-30% 较安全 | 10%-20% 值得注意 | <10% 危险
```

### 📝 实战例题 · 本量利

**题目**：某产品单价100元，单位变动成本60元，固定成本20万元，目标利润10万元。

```
单位边际贡献 = 100 - 60 = 40元
边际贡献率 = 40/100 = 40%

保本点销售量 = 200000 / 40 = 5000件
保本点销售额 = 200000 / 40% = 50万元

保利点销售量 = (200000+100000) / 40 = 7500件
保利点销售额 = 300000 / 40% = 75万元
```

### 二、标准成本差异分析（⭐⭐⭐）

```
总差异 = 实际成本 - 标准成本

差异分解（两因素法）：
  价格差异 = (实际价格 - 标准价格) × 实际用量
  用量差异 = (实际用量 - 标准用量) × 标准价格

各成本项目的差异名称：
  直接材料：材料价格差异 + 材料用量差异
  直接人工：工资率差异 + 人工效率差异
  变动制造费用：耗费差异 + 效率差异
  固定制造费用：耗费差异 + 产量差异 + 效率差异（三因素法）
```

> 🔥 **记忆口诀**：所有差异都是"价差 + 量差"
> - 价差 = (实际价 - 标准价) × **实际量**
> - 量差 = (实际量 - 标准量) × **标准价**
> - 交叉部分归价差（因为用的是实际量）

### 📝 实战例题 · 标准成本

**题目**：某产品标准用料5kg/件、标准单价10元/kg。本月生产1000件，实际用料5200kg，实际单价11元/kg。

```
标准成本 = 1000 × 5 × 10 = 50000元
实际成本 = 5200 × 11 = 57200元
总差异 = 57200 - 50000 = 7200元（不利）

价格差异 = (11-10) × 5200 = 5200元（不利）
用量差异 = (5200-5000) × 10 = 2000元（不利）
验证：5200 + 2000 = 7200 ✅
```

### 三、责任成本与责任中心

| 责任中心 | 考核指标 | 特点 |
|:---|:---|:---|
| 成本中心 | 成本差异（可控成本） | 只控制成本，不控制收入和投资 |
| 利润中心 | 可控边际贡献 | 控制成本和收入 |
| 投资中心 | 投资报酬率、剩余收益 | 控制成本、收入和投资 |

```
投资报酬率（ROI）= 利润 / 投资额
剩余收益（RI）= 利润 - 投资额 × 最低报酬率

💡 ROI的缺陷：可能导致放弃高于资本成本但低于部门ROI的项目
   RI的优点：能避免ROI的短视问题
```

### 📝 仿真题

**【单选】** 保本点销售量计算公式中，分母是（ ）。
A. 单价  B. 单位变动成本  C. 边际贡献率  D. 单位边际贡献

**答案：D** — 保本点销售**量** = 固定成本 / 单位边际贡献。注意：保本点销售**额**的分母才是边际贡献率(C)。

**【判断】** 材料价格差异应由采购部门负责，材料用量差异应由生产部门负责。（ ）

**答案：✅** — 价格差异由采购决定，用量差异由生产部门的生产效率决定。

## 第九章 收入与分配管理 ⭐⭐⭐

> 🎯 分值：8-12分 | 题型：全题型（计算题/综合题高频） | 难度：★★★★☆
> 近年趋势：销售预测、产品定价、股利分配政策是高频考点，几乎年年出计算题。

### 一、销售预测

#### 定量分析法

| 方法 | 公式/思路 | 适用 |
|:---|:---|:---|
| 算术平均法 | 预测值 = 各期销售量之和 / 期数 | 各期销售波动不大 |
| 加权平均法 | 近期权重大、远期权重小 | 有明显趋势 |
| 移动平均法 | 取最近n期平均值 | 平滑季节波动 |
| 指数平滑法 | Y_t+1 = α·X_t + (1-α)·Y_t | 最常考，α越大越重视近期 |
| 回归分析法 | Y = a + bX | 变量间有线性关系 |

```
指数平滑法（⭐重点公式）：
  预测值 = α × 上期实际值 + (1-α) × 上期预测值

  α = 平滑系数（0 < α < 1）
  α越大 → 越重视最近的实际数据
  α越小 → 预测值越平滑（趋于稳定）
```

### 📝 实战例题 · 指数平滑法

**题目**：某产品上年实际销量120万件，上年预测销量110万件，平滑系数α=0.6，预测本年销量。

```
Y = 0.6 × 120 + (1-0.6) × 110
  = 72 + 44
  = 116万件
```

### 二、产品定价管理

#### 定价方法

| 方法 | 公式 | 特点 |
|:---|:---|:---|
| **全部成本费用加成** | 价格 = 全部成本×(1+成本利润率) | 最基本的方法 |
| **变动成本定价法** | 价格 = 变动成本×(1+贡献边际率) | 特殊订单/剩余产能 |
| 保本点定价法 | 价格 = 单位完全成本 | 最低底线 |
| 目标利润定价法 | 价格 = (完全成本+目标利润)/销量 | 最常用 |

```
全部成本费用加成定价：
  单位价格 = 单位成本 × (1 + 成本利润率)

变动成本定价法（⭐常考）：
  单位价格 = 单位变动成本 × (1 + 贡献边际率)

💡 变动成本定价法只适用于特殊订单且有剩余产能时
   正常销售必须用全部成本定价，否则长期亏损
```

#### 定价策略

| 策略 | 含义 | 适用 |
|:---|:---|:---|
| 撇脂定价 | 高价上市，逐步降价 | 新产品、技术领先、需求弹性小 |
| 渗透定价 | 低价上市，快速占领市场 | 需求弹性大、竞争激烈 |
| 心理定价 | 尾数定价(9.9元)、整数定价 | 消费品 |

### 三、纳税管理

```
纳税管理目标：合法、合规前提下，降低税负成本。

企业重点税种：
  增值税（流转税）
  企业所得税（所得税）
  个人所得税（代扣代缴）

纳税筹划的基本方法：
  1. 利用税收优惠政策
  2. 合理安排纳税时间（递延纳税）
  3. 转让定价
  4. 利用税法漏洞（注意合规风险）
```

> ⚠️ **考试注意**：纳税管理主要考选择题，理解概念即可，不会出大计算。

### 📝 仿真题

**【单选】** 采用指数平滑法进行销售预测时，平滑系数α越大，则（ ）。
A. 预测值越平滑  B. 越重视近期实际数据  C. 越重视远期数据  D. 预测值越保守

**答案：B** — α越大，最近一期实际值的权重越大，预测值对最新变化的反应越灵敏。

**【判断】** 变动成本定价法适用于企业所有产品的正常定价。（ ）

**答案：×** — 变动成本定价法只适用于特殊订单且有剩余产能的情况，正常销售应采用全部成本加成定价。

### 四、股利分配管理（⭐⭐⭐高频考点！）

#### 利润分配顺序

```
税后净利润的分配顺序：
  1. 弥补以前年度亏损（5年内可税前弥补）
  2. 提取法定盈余公积（净利润的10%，累计达注册资本50%可不再提）
  3. 提取任意盈余公积（股东大会决定比例）
  4. 向股东分配股利

⚠️ 没有利润不得分配股利！（但可以用盈余公积弥补亏损）
```

#### 股利政策（⭐⭐⭐必背！）

| 政策 | 做法 | 优点 | 缺点 |
|:---|:---|:---|:---|
| **剩余股利政策** | 先满足投资需要，剩余才分 | 保持最优资本结构、资本成本最低 | 股利不稳定 |
| **固定或稳定增长** | 每年固定股利或稳定增长 | 股价稳定、投资者信心强 | 可能造成资金短缺 |
| **固定股利支付率** | 按净利润固定比例分配 | 与盈利挂钩，公平 | 股利波动大 |
| **低正常+额外股利** | 低基础股利+盈利好时发额外 | 灵活、兼顾稳定和弹性 | 额外股利难持续 |

> 🔥 **考试核心结论**：
> - **剩余股利政策**：适用于公司**初创期**，投资机会多
> - **固定或稳定增长**：适用于**成熟期**，最常用
> - 考试问"最优资本结构" → 选**剩余股利政策**
> - 考试问"稳定股价" → 选**固定或稳定增长**

#### 股利支付方式

| 方式 | 特点 |
|:---|:---|
| **现金股利** | 最常见，减少现金和留存收益 |
| **股票股利** | 不减少现金，只是所有者权益内部转换（留存收益→股本） |
| 财产股利 | 以非现金资产支付（少见） |
| 负债股利 | 以应付票据支付（少见） |

```
股票股利的影响：
  ✅ 股数增加
  ✅ 每股面值不变
  ❌ 每股收益下降（总利润不变，股数变多）
  ❌ 每股市价下降
  ✅ 股东持股比例不变
  ✅ 所有者权益总额不变（只是内部结构变了）
```

### 五、股票分割与股票回购

```
股票分割（拆股）：
  例：1股拆成2股
  ✅ 股数翻倍、每股面值减半
  ✅ 每股市价降低、流通性增强
  ❌ 所有者权益总额和内部结构都不变

股票回购：
  公司用现金从市场买回自己的股票
  ✅ 减少流通股数 → 提高每股收益 → 可能推高股价
  ✅ 可替代现金股利（在某些税制下对股东更有利）
```

> 💡 **股票分割 vs 股票股利**：
> - 股票分割：面值变、所有者权益结构不变
> - 股票股利：面值不变、所有者权益结构变（留存收益→股本）

### 📝 实战例题 · 剩余股利政策

**题目**：某公司净利润1000万，最优资本结构为负债40%、权益60%。明年投资项目需资金800万。按剩余股利政策，应分多少股利？

```
投资所需权益资金 = 800 × 60% = 480万
可分配股利 = 1000 - 480 = 520万

结论：先用480万满足投资的权益资金需求，剩余520万全部分配。
```

### 📝 仿真题

**【单选】** 下列股利政策中，最有利于保持最佳资本结构的是（ ）。
A. 固定股利政策  B. 剩余股利政策  C. 固定股利支付率政策  D. 低正常加额外股利政策

**答案：B** — 剩余股利政策优先保证投资所需权益资金，剩余才分，能保持最优资本结构。

**【多选】** 发放股票股利会产生的影响有（ ）。
A. 引起所有者权益总额变动  B. 引起所有者权益内部结构变动
C. 导致每股收益下降  D. 导致股东持股比例变化

**答案：BC** — A错（总额不变），D错（比例不变），B对（留存→股本），C对（股数增多→每股收益降低）。

## 第十章 财务分析与评价 ⭐⭐⭐

> 🎯 分值：8-12分 | 题型：全题型（计算题/综合题必考） | 难度：★★★☆☆
> 近年趋势：财务比率分析（偿债、营运、盈利能力）和杜邦分析是每年必考内容。

### 一、财务分析方法

| 方法 | 做法 | 特点 |
|:---|:---|:---|
| **比较分析法** | 与标准/历史/行业比 | 最基本 |
| **比率分析法** | 计算各种财务比率 | 最常用、最重要 |
| **因素分析法** | 逐个替换因素，分析影响 | 连环替代法/差额分析法 |

#### 因素分析法（连环替代法）⭐⭐

```
假设：指标M = A × B × C

基期：M₀ = A₀ × B₀ × C₀
第1次替代：A₁ × B₀ × C₀  → A因素的影响 = 第1次 - M₀
第2次替代：A₁ × B₁ × C₀  → B因素的影响 = 第2次 - 第1次
第3次替代：A₁ × B₁ × C₁  → C因素的影响 = 第3次 - 第2次

💡 规则：
  1. 每次只替换一个因素
  2. 替换顺序：数量因素在前，价格因素在后
  3. 各因素影响之和 = 总差异
```

### 二、偿债能力分析

#### 短期偿债能力

| 指标 | 公式 | 标准/含义 |
|:---|:---|:---|
| **流动比率** | 流动资产/流动负债 | 一般≥2较好 |
| **速动比率** | 速动资产/流动负债 | 一般≥1较好 |
| **现金比率** | (货币资金+交易性金融资产)/流动负债 | 最严格 |

```
速动资产 = 流动资产 - 存货 - 预付账款 - 一年内到期的非流动资产 - 其他流动资产

💡 为什么扣除存货？
  存货变现速度慢、变现价值不确定（可能跌价）
  
⚠️ 流动比率的局限：
  虚高情况：大量存货积压 → 流动比率高但实际偿债能力差
  行业差异：超市（周转快）流动比率低也正常
```

#### 长期偿债能力

| 指标 | 公式 | 含义 |
|:---|:---|:---|
| **资产负债率** | 负债/资产 | 越高风险越大，一般40%-60% |
| **产权比率** | 负债/所有者权益 | 反映财务杠杆 |
| **权益乘数** | 资产/所有者权益 = 1/(1-资产负债率) | 杜邦分析核心指标 |
| **利息保障倍数** | EBIT/利息费用 | ≥1才能偿付利息 |

```
三者的关系：
  资产负债率 = 负债/资产
  产权比率 = 负债/权益
  权益乘数 = 资产/权益 = 1 + 产权比率

  三个指标同方向变动：一个高，其他两个也高
```

### 三、营运能力分析

| 指标 | 公式 | 含义 |
|:---|:---|:---|
| **应收账款周转率** | 营业收入/应收账款平均余额 | 越高回款越快 |
| **存货周转率** | 营业成本/存货平均余额 | 越高周转越快 |
| **流动资产周转率** | 营业收入/流动资产平均余额 | 越高效率越高 |
| **固定资产周转率** | 营业收入/固定资产平均净值 | 越高利用率越高 |
| **总资产周转率** | 营业收入/资产平均总额 | 综合指标 |

```
周转天数 = 365 / 周转率

💡 注意：
  存货周转率的分子用"营业成本"（不是营业收入！）
  其他周转率的分子都用"营业收入"
  
  分母都用"平均余额" = (期初+期末)/2
```

> 🔥 **高频考点**：存货周转率分子为什么用营业成本？
> 因为存货是按成本计价的，用成本比用收入更能反映真实周转速度。

### 📝 实战例题 · 连环替代法

**题目**：某公司材料费用 = 产量 × 单耗 × 单价。基期：100件×5kg×10元=5000元。实际：120件×4.5kg×11元=5940元。分析各因素影响。

```
基期：100 × 5 × 10 = 5000
第1次：120 × 5 × 10 = 6000  → 产量影响 = 6000-5000 = +1000
第2次：120 × 4.5 × 10 = 5400 → 单耗影响 = 5400-6000 = -600
第3次：120 × 4.5 × 11 = 5940 → 单价影响 = 5940-5400 = +540

验证：1000 + (-600) + 540 = 940 = 5940-5000 ✅
```

### 四、盈利能力分析

| 指标 | 公式 | 含义 |
|:---|:---|:---|
| **营业净利率** | 净利润/营业收入 | 每1元收入赚多少净利 |
| **总资产净利率（ROA）** | 净利润/资产平均总额 | 资产的综合盈利能力 |
| **净资产收益率（ROE）** | 净利润/所有者权益平均余额 | 股东投入的回报率，**最核心** |

```
💡 ROE是衡量盈利能力最综合、最重要的指标
   也是杜邦分析体系的核心

其他盈利指标：
  每股收益（EPS）= 归属普通股净利润 / 普通股加权平均数
  市盈率（PE）= 每股市价 / 每股收益
  市净率（PB）= 每股市价 / 每股净资产
```

### 五、发展能力分析

| 指标 | 公式 | 含义 |
|:---|:---|:---|
| 营业收入增长率 | (本年收入-上年收入)/上年收入 | 市场拓展能力 |
| 总资产增长率 | (年末资产-年初资产)/年初资产 | 规模扩张速度 |
| 营业利润增长率 | (本年利润-上年利润)/上年利润 | 盈利成长性 |
| 资本保值增值率 | 年末所有者权益/年初所有者权益 | >1说明增值 |
| 资本积累率 | 本年所有者权益增长额/年初所有者权益 | 积累能力 |

### 六、杜邦分析体系（⭐⭐⭐必考！）

```
核心公式（必背！）：

  净资产收益率(ROE) = 营业净利率 × 总资产周转率 × 权益乘数

  即：ROE = (净利润/收入) × (收入/资产) × (资产/权益)

💡 拆解含义：
  营业净利率 → 反映盈利能力（赚不赚钱）
  总资产周转率 → 反映营运能力（资产用得好不好）
  权益乘数 → 反映偿债能力/杠杆（借了多少钱）

  提高ROE的三条路：
  1. 提高利润率（提质量）
  2. 加快周转（提效率）
  3. 加大杠杆（多借债）→ 风险也增大
```

> 🔥 **杜邦分析的精髓**：把ROE拆成三个驱动因素，找到企业盈利的核心动力。
> - 茅台型：高利润率驱动
> - 沃尔玛型：高周转率驱动
> - 银行型：高杠杆驱动

### 七、综合绩效评价

#### 管理层业绩评价

```
经济增加值（EVA）：
  EVA = 税后净营业利润 - 资本成本
      = NOPAT - WACC × 投入资本

  EVA > 0 → 创造了超过资本成本的价值
  EVA < 0 → 毁损了股东价值

💡 EVA比净利润更科学，因为考虑了资本的机会成本
```

### 📝 实战例题 · 杜邦分析

**题目**：某公司净利润500万，营业收入5000万，资产总额4000万，所有者权益2000万。计算杜邦分析三因素和ROE。

```
营业净利率 = 500/5000 = 10%
总资产周转率 = 5000/4000 = 1.25次
权益乘数 = 4000/2000 = 2

ROE = 10% × 1.25 × 2 = 25%

验证：500/2000 = 25% ✅
```

### 📝 仿真题

**【单选】** 杜邦分析体系的核心指标是（ ）。
A. 营业净利率  B. 总资产周转率  C. 净资产收益率  D. 权益乘数

**答案：C** — ROE是杜邦分析的顶层核心指标，其他三个是分解因素。

**【多选】** 下列各项中，会导致总资产周转率下降的有（ ）。
A. 赊销增加导致应收账款增加  B. 销售收入大幅增长
C. 大量购置固定资产尚未投产  D. 存货积压

**答案：ACD** — A增加应收（分母增大）、C增加资产（分母增大）、D存货积压（分母增大），都导致周转率下降。B使分子增大，周转率上升。

**【判断】** 存货周转率的分子应当使用营业收入。（ ）

**答案：×** — 存货周转率分子用**营业成本**，因为存货按成本计价。
