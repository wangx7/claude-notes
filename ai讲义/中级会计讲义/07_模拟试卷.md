## 四、计算分析题（共2题，每题10分，共20分）

### 计算题1：长期股权投资（权益法）

甲公司2025年1月1日以1200万元取得乙公司30%的股权，能够施加重大影响，采用权益法核算。取得投资时乙公司可辨认净资产公允价值为3800万元。

2025年度乙公司实现净利润500万元，宣告分配现金股利200万元。乙公司一项管理用固定资产公允价值比账面价值高100万元，剩余使用年限10年（直线法）。

**要求**：编制甲公司2025年相关分录。

**答案**：

```
(1) 初始投资成本 vs 应享有份额：
    初始成本 = 1200万
    应享份额 = 3800 × 30% = 1140万
    1200 > 1140 → 不调整（差额60万为商誉）

    借：长期股权投资—投资成本   1200
        贷：银行存款              1200

(2) 调整后净利润 = 500 - 100/10 = 490万（扣除公允价值调整的折旧差异）
    确认投资收益 = 490 × 30% = 147万

    借：长期股权投资—损益调整   147
        贷：投资收益              147

(3) 宣告分红：
    应收股利 = 200 × 30% = 60万
    
    借：应收股利                60
        贷：长期股权投资—损益调整  60
```

### 计算题2：所得税会计

甲公司2025年利润总额1000万元，所得税率25%。存在以下暂时性差异：
1. 年末存货账面价值800万，已计提跌价准备50万，计税基础800万
2. 年末交易性金融资产账面价值（公允）600万，计税基础500万
3. 预计负债（产品质量保证）账面价值80万，计税基础0

年初无递延所得税余额。

**要求**：计算当期所得税费用并编制分录。

**答案**：

```
(1) 分析暂时性差异：
    存货：账面750（800-50）< 计税800 → 可抵扣差异50万 → DTA=50×25%=12.5万
    交易性金融资产：账面600 > 计税500 → 应纳税差异100万 → DTL=100×25%=25万
    预计负债：账面80 > 计税0 → 可抵扣差异80万 → DTA=80×25%=20万

(2) 应纳税所得额 = 1000 + 50（跌价准备纳税调增）- 100（金融资产已算公允）+ 80（保证费用纳税调增）
    = 1000 + 50 - 100 + 80 = 1030万
    
    ⚠️ 更准确计算：
    应纳税所得额 = 利润总额 + 纳税调增 - 纳税调减
    = 1000 + 50 + 80 - 100 = 1030万

    当期应交所得税 = 1030 × 25% = 257.5万

(3) 递延所得税：
    DTA增加 = 12.5 + 20 = 32.5万
    DTL增加 = 25万
    递延所得税费用 = 25 - 32.5 = -7.5万（负号=减少费用）

(4) 所得税费用 = 257.5 + (-7.5) = 250万
    验证：1000 × 25% = 250万 ✅

(5) 分录：
    借：所得税费用            250
        递延所得税资产          32.5
        贷：应交税费—应交所得税   257.5
            递延所得税负债        25
```

## 四、计算分析题（共2题，共25分）

### 计算题1：资本成本与杠杆（12分）

某公司销售收入1000万，变动成本率60%，固定成本160万，利息费用40万，无优先股。公司债务资本400万（利率8%），权益资本600万（Ks=15%），所得税率25%。

**要求**：（1）计算DOL、DFL、DTL；（2）计算WACC。

**答案**：

```
(1) M = 1000×(1-60%) = 400万
    EBIT = 400 - 160 = 240万

    DOL = M/EBIT = 400/240 = 1.67
    DFL = EBIT/(EBIT-I) = 240/(240-40) = 1.2
    DTL = DOL×DFL = 1.67×1.2 = 2

(2) 债务成本（税后）= 8%×(1-25%) = 6%
    债务比重 = 400/1000 = 40%
    权益比重 = 600/1000 = 60%

    WACC = 40%×6% + 60%×15%
         = 2.4% + 9%
         = 11.4%
```

### 计算题2：投资决策（13分）

某项目初始投资300万（全部为固定资产），直线法折旧，残值0，使用期5年。每年营业收入200万，付现成本100万，所得税率25%，折现率10%。(P/A,10%,5)=3.7908。

**要求**：（1）计算每年NCF；（2）计算NPV并判断可行性。

**答案**：

```
(1) 年折旧 = 300/5 = 60万
    NCF = 收入×(1-T) - 付现成本×(1-T) + 折旧×T
        = 200×75% - 100×75% + 60×25%
        = 150 - 75 + 15
        = 90万

(2) NPV = 90×(P/A,10%,5) - 300
        = 90×3.7908 - 300
        = 341.17 - 300
        = 41.17万 > 0

    NPV > 0，项目可行，可创造41.17万超额价值。
```

## 四、简答题（共2题，每题10分，共20分）

### 简答题1：合同法（10分）

甲公司（卖方）与乙公司（买方）签订了一份货物买卖合同，合同约定：甲公司于2025年3月1日前交货，货款100万元，乙公司于收货后30日内付款；甲公司收取定金10万元。合同还约定了违约金条款，约定一方违约须向对方支付违约金20万元。

2025年2月，甲公司发现乙公司转移财产、抽逃资金，有明显的不能履行合同的迹象。甲公司遂停止生产，并通知乙公司暂停履行合同，要求乙公司在30日内提供担保。乙公司既未提供担保，也未恢复履行能力，甲公司随后宣布解除合同，并要求乙公司赔偿损失。

乙公司则主张：（1）甲公司无权停止履行，应当继续按约交货；（2）合同应由甲公司承担违约责任；（3）要求甲公司双倍返还定金20万元。

**要求**：逐一分析乙公司三项主张是否成立，并说明理由。

**答案**：

**(1) 乙公司"甲无权停止履行"的主张不成立。**

甲公司的行为属于行使**不安抗辩权**。依法，先履行方有确切证据证明后履行方有下列情形之一的，可以中止履行：①经营状况严重恶化；②转移财产、抽逃资金以逃避债务；③丧失商业信誉；④有丧失或可能丧失履行能力的其他情形。乙公司转移财产、抽逃资金，符合法定情形。甲公司中止履行后应及时通知对方，并要求提供担保，程序合法。

**(2) 乙公司要求甲承担违约责任的主张不成立。**

乙公司在合理期限内（30日）既未提供充分担保，也未恢复履行能力，甲公司依法有权解除合同。在此情况下，甲公司解除合同属于合法行使权利，**不构成违约**，违约责任应由乙公司承担。

**(3) 乙公司要求双倍返还定金20万元的主张不成立。**

定金罚则规定：**给付定金方**（乙公司）违约，无权要求返还定金；**收取定金方**（甲公司）违约，须双倍返还。本案中，乙公司转移财产、拒不提供担保，构成违约（预期违约），系乙公司违约，故乙公司无权要求返还定金，甲公司有权没收定金10万元。

> ⚠️ **注意**：违约金与定金只能择一适用，甲公司在主张没收定金与主张违约金之间只能选其一。

### 简答题2：公司法（10分）

甲有限责任公司（以下简称"甲公司"）注册资本1000万元，股东为A（持股60%）、B（持股30%）、C（持股10%）。

2025年5月，A拟将其持有的甲公司30%股权对外转让给D，转让价格为400万元。A将转让事项以书面方式通知了B和C。B在收到通知后第20天书面表示以同等条件优先购买；C在30天内未作任何回应。

同年8月，甲公司股东会召开，议题为：（1）修改公司章程；（2）向银行借款500万元。B因出差缺席，未委托他人出席。A和C出席会议（A代表60%表决权，C代表10%表决权），两项决议均获A和C赞成通过。

**要求**：
（1）B主张优先购买30%股权是否有效？C是否放弃了优先购买权？
（2）两项股东会决议是否有效？请分别分析。

**答案**：

**(1) 关于优先购买权：**

**B的主张有效。** 依据公司法，股东对外转让股权须书面通知其他股东，其他股东在收到通知后**30日内**可行使优先购买权。B在第20天（30日内）书面表示以同等条件（400万元）购买，符合条件，优先购买权有效。

**C放弃了优先购买权。** C在30日内未作任何回应，依法视为**放弃优先购买权**。

> 补充：本案中B和C均主张优先购买的情况不存在，只有B主张。A可将30%股权转让给B（以同等条件400万元）；若B已优先购买，则A剩余30%（持股从60%降至30%）可继续对外转让给D。

**(2) 关于两项股东会决议：**

**①修改公司章程的决议无效。**

修改公司章程属于**特别决议事项**，须经代表**2/3以上表决权**的股东通过。本次会议A（60%）+C（10%）= 70% < 2/3（约66.7%虽满足，但B未出席、未委托）。

> 注意：2/3约为66.7%，A+C=70% > 66.7%，从数字看似乎满足，但有限公司股东会须依法召集，B未出席且未委托，会议程序上需审查是否符合章程和法律规定（如提前通知等）。若程序合法，A+C=70%确实满足2/3以上要求，该决议**有效**。

**②向银行借款500万元的决议有效。**

银行借款属于普通经营事项，为**普通决议**，须经代表**过半数表决权**的股东通过。A（60%）+C（10%）=70% > 50%，决议通过，**有效**。

> 💡 **考点提示**：判断决议是否有效，关键看两点：①是普通决议还是特别决议（看事项性质）；②出席会议的表决权比例是否达到法定门槛。

## 五、综合案例题（共1题，25分）

### 综合题：公司法 + 合同法 + 票据法综合

**【背景材料】**

甲公司（股份有限公司，已上市）、乙公司（有限责任公司）、丙公司之间发生了以下一系列法律事件：

**事件一**：2025年1月，甲公司与乙公司签订一份采购合同，约定乙公司向甲公司供应原材料500吨，单价2000元/吨，总价100万元。合同约定：甲公司预付定金10万元；乙公司须于2025年3月31日前完成交货；货物风险于甲公司指定仓库收货时转移。

**事件二**：2025年2月，甲公司为支付货款向乙公司签发了一张银行承兑汇票，票面金额100万元，到期日2025年9月30日。乙公司随后将该汇票背书转让给丙公司，用于支付丙公司的工程款，背书时注明"限丙公司使用"。丙公司收到汇票后，又将该汇票背书转让给丁公司。

**事件三**：2025年3月，乙公司按约交货480吨（短少20吨），货物在运输途中遇暴雨，其中10吨原材料在运至甲公司仓库途中受损。甲公司以乙公司未足额交货、且货物受损为由，拒绝付款。

**事件四**：2025年4月，甲公司召开股东大会，审议以下议案：（1）向某银行提供5亿元担保（超过最近一期经审计净资产50%）；（2）变更公司主营业务；（3）修改公司章程。三项议案均在出席会议的股东中获得2/3以上赞成票通过。甲公司随后对外披露了上述决议，但未就担保事项单独披露。

**要求**：

**（1）【合同法】** 事件一中，运输途中10吨原材料受损的风险由谁承担？甲公司以货物受损为由拒绝付款是否有依据？（5分）

**（2）【票据法】** 事件二中，乙公司背书时注明"限丙公司使用"，丙公司能否再次背书转让给丁公司？丁公司能否向甲公司（出票人/承兑人）主张付款？（6分）

**（3）【合同法】** 事件三中，乙公司仅交付480吨（短少20吨），甲公司应如何处理？（4分）

**（4）【公司法·上市公司】** 事件四中，三项股东大会决议是否均合法有效？甲公司的信息披露是否存在问题？（10分）

---

**答案**：

**（1）风险承担与拒付分析（5分）**

**风险承担：由乙公司承担。**

合同约定"货物风险于甲公司指定仓库收货时转移"，即采用**到达主义**（非交付承运人即转移）。10吨原材料在运至甲公司仓库途中受损，尚未到达指定仓库，风险尚未转移，仍由**乙公司**承担。

**甲公司以货物受损为由拒绝付款无依据（仅就该10吨而言）。**

货物受损风险在乙公司，应由乙公司承担损失（可向承运人索赔）。甲公司在受损货物实际验收后，须就已收到货物部分支付货款。但因乙公司短少20吨，甲公司可就未交付部分（20吨×2000元=4万元）拒付，或主张违约责任。

**（2）票据背书与付款分析（6分）**

**①丙公司能否再次背书转让：可以，但乙公司对此后的背书不承担保证责任。**

乙公司背书时记载"限丙公司使用"（即禁止转让背书），依据票据法：背书人记载"不得转让"的，其后手再背书转让时，原背书人（乙公司）对后手（丁公司）不再承担保证付款责任，但背书转让本身**有效**。故丙公司可以将汇票背书转让给丁公司。

**②丁公司能否向甲公司主张付款：可以。**

甲公司作为银行承兑汇票的**承兑人**，是票据的主债务人，对所有合法持票人承担绝对付款责任。丁公司通过连续背书取得汇票，属于合法持票人，可在到期日（2025年9月30日）向甲公司的开户行提示付款，甲公司（承兑行）须无条件付款。

> ⚠️ 注意：丁公司不能向**乙公司**主张背书保证责任（因乙公司禁转背书的限制），但可向甲公司（承兑人）和丙公司（背书人）追索。

**（3）乙公司短少交货的处理（4分）**

乙公司仅交付480吨，短少20吨，构成**不完全履行**（部分违约）。甲公司有以下选择：

- **要求继续履行**：要求乙公司补足剩余20吨原材料；
- **要求赔偿损失**：就20吨未交付部分（4万元货物价值）主张赔偿；
- **合同解除**：若乙公司拒绝补足，且合同目的因此不能实现，甲公司可解除合同，要求返还定金并赔偿损失；
- **定金罚则**：乙公司违约，甲公司有权没收定金10万元（但不能同时主张违约金）。

**（4）股东大会决议及信息披露分析（10分）**

**① 三项决议的合法性：**

| 议案 | 决议类型 | 通过条件 | 本次情况 | 结论 |
|:---|:---|:---|:---|:---|
| 提供5亿元担保 | **特别事项**（上市公司重大担保须股东大会批准） | 出席会议2/3以上赞成 | 已获2/3以上通过 | **有效** |
| 变更公司主营业务 | **特别决议**（重大经营变化，须修改章程配套） | 出席会议2/3以上赞成 | 已获2/3以上通过 | **有效** |
| 修改公司章程 | **特别决议** | 出席会议2/3以上赞成 | 已获2/3以上通过 | **有效** |

三项决议均合法有效（均满足特别决议要求）。

**② 信息披露问题：**

甲公司的信息披露**存在问题**。

依据证券法关于上市公司重大事项临时信息披露的规定，以下事项属于**重大事件**，须及时披露：
- 公司重大担保（超过净资产50%的对外担保属于重大担保）；
- 修改公司章程；
- 公司主营业务发生重大变化。

甲公司虽披露了三项决议，但**未就担保事项单独、详细披露**（仅在决议公告中附带提及），违反了"应当在重大担保发生后及时单独发布临时报告"的要求。甲公司应当就5亿元担保事项单独发布**临时报告**，详细披露担保对象、担保金额、担保期限等信息。
