## 第十一章 借款费用 ⭐⭐

> 🎯 分值：3-5分 | 题型：单选、多选、判断、计算 | 难度：★★☆☆☆
> 近年趋势：资本化金额的计算（一般借款+专门借款）几乎年年必考。

### 一、核心概念

**借款费用**：因借款而发生的利息及其他相关成本，包括利息、折价/溢价摊销、辅助费用、外币借款汇兑差额。

**关键区分**：

| | 资本化（计入资产成本） | 费用化（计入财务费用） |
|:---|:---|:---|
| 条件 | 用于购建/生产**符合资本化条件的资产** | 其他情况 |
| 什么是符合条件的资产 | 需要经过相当长时间（≥1年）才能达到可使用/可销售状态的资产 | — |
| 典型例子 | 自建厂房、需要长期生产的大型设备、开发阶段无形资产 | 短期建设项目、已完工资产 |

### 二、资本化期间（三个起止条件）

**开始资本化**（三个条件同时满足）：
1. 资产支出**已经发生**
2. 借款费用**已经发生**
3. 使资产达到可使用状态的**购建活动已经开始**

**暂停资本化**：非正常中断且连续超过3个月 → 暂停（正常中断不暂停！）

**停止资本化**：资产达到预定可使用/可销售状态

> ⚠️ **满分陷阱**：
> - 正常的工程进度中断（如冬季停工）→ **不暂停**
> - 非正常中断（如资金不足、质量纠纷）→ **暂停**
> - 部分完工可单独使用 → 该部分**停止资本化**

### 三、资本化金额计算

#### ① 专门借款

```
资本化金额 = 专门借款当期实际发生的利息 - 尚未动用的闲置资金的收益

大白话：借了专门的钱盖楼，利息算在楼的成本里，
但还没用完的钱存银行赚的利息要扣掉。
```

#### ② 一般借款

```
累计资产支出超过专门借款部分 × 一般借款加权平均利率 = 一般借款资本化金额

加权平均利率 = 一般借款当期利息总额 ÷ 一般借款本金加权平均数
```

#### ③ 合计

```
当期资本化总额 = 专门借款资本化金额 + 一般借款资本化金额
其中：一般借款资本化金额 ≤ 一般借款当期实际利息
```

### 📝 实战例题 · 借款费用资本化

**题目**：甲公司2025年1月1日开始建造厂房。
- 专门借款：1月1日借入2000万元，年利率6%
- 一般借款：原有借款3000万元，年利率5%
- 资产支出：1月1日支出800万，7月1日支出1500万
- 闲置资金年收益率1.5%
- 12月31日厂房完工

```
第1步：专门借款资本化
  专门借款利息 = 2000 × 6% = 120万
  闲置资金：
    1月1日-6月30日闲置 = 2000 - 800 = 1200万（6个月）
    7月1日-12月31日闲置 = 2000 - 800 - 1500 = -300 → 已全部用完，闲置=0
  闲置收益 = 1200 × 1.5% × 6/12 = 9万
  专门借款资本化金额 = 120 - 9 = 111万

第2步：一般借款资本化
  超出专门借款的支出：
    7月1日起超出 = (800+1500) - 2000 = 300万（占用6个月）
  累计支出超额加权 = 300 × 6/12 = 150万
  一般借款利率 = 5%
  一般借款资本化金额 = 150 × 5% = 7.5万

第3步：合计
  资本化总额 = 111 + 7.5 = 118.5万
```

### 📝 仿真题

**【判断】** 企业建造厂房期间因工程质量问题停工3个月，该期间的借款费用应当继续资本化。（ ）

**答案：×** — 质量问题属于**非正常中断**，应暂停资本化。

## 第十二章 或有事项 ⭐⭐

> 🎯 分值：3-5分 | 题型：单选、多选、判断 | 难度：★★☆☆☆
> 近年趋势：预计负债的确认条件、或有负债vs预计负债的区分是选择题高频。

### 一、核心概念辨析

| 概念 | 定义 | 是否确认 |
|:---|:---|:---|
| **预计负债** | 过去事项引起的、履行义务很可能导致经济利益流出、金额能可靠计量 | ✅ 确认（记入资产负债表） |
| **或有负债** | 可能的义务，或金额不能可靠计量的现时义务 | ❌ 不确认，只**披露** |
| **或有资产** | 可能的资产 | ❌ 不确认，基本可确定时才**披露** |

**预计负债确认三条件**（同时满足）：
1. 过去事项形成的**现时义务**
2. 履行该义务**很可能（>50%）**导致经济利益流出
3. 金额能够**可靠计量**

> 💡 **概率判断表**：

| 概率 | 术语 | 处理 |
|:---|:---|:---|
| > 95% | 基本确定 | 确认资产（或有资产变成资产） |
| 50%-95% | 很可能 | 确认预计负债 |
| 5%-50% | 可能 | 只披露（或有负债） |
| < 5% | 极小可能 | 不披露不确认 |

### 二、预计负债的计量

```
最佳估计数的确定：
- 单个项目：最可能发生的金额
- 多个项目：加权平均数（各种可能金额 × 概率）
- 有上下限：取中间值

如果预期可以获得第三方补偿：
  补偿金额单独确认为资产（其他应收款），但 ≤ 预计负债金额
```

### 三、常见或有事项

| 事项 | 处理 |
|:---|:---|
| **未决诉讼** | 败诉很可能且金额可计量 → 确认预计负债 |
| **产品质量保证** | 按历史经验估计 → 确认预计负债 |
| **亏损合同** | 执行合同的损失 vs 违约金取低的 → 确认预计负债 |
| **为其他企业提供担保** | 被担保方很可能违约 → 确认预计负债 |

**亏损合同处理**（高频考点）：

```
亏损合同：执行合同会亏损

如果存在标的资产（如已采购的原材料）：
  先对标的资产做减值测试

如果无标的资产：
  预计负债 = min(执行合同的损失, 不执行合同的违约金)
```

### 📝 实战例题

**题目**：甲公司签订合同向乙公司销售A产品，合同价100万元。至年末A产品尚未生产，预计生产成本130万元。如不履约需支付违约金20万元。

```
执行合同的损失 = 130 - 100 = 30万
不执行合同的违约金 = 20万

应确认的预计负债 = min(30, 20) = 20万（选择违约更划算）

借：营业外支出    20
    贷：预计负债    20
```

### 📝 仿真题

**【单选】** 下列各项中，应确认为预计负债的是（ ）。
A. 可能的产品质量保证义务
B. 很可能败诉且赔偿金额能合理估计的未决诉讼
C. 已贴现的商业承兑汇票
D. 为其他企业提供担保，但被担保方经营正常

**答案：B** — 同时满足三个条件。A是"可能"不是"很可能"；C是或有负债（披露）；D被担保方正常则不太可能赔付。

## 第十三章 收入 ⭐⭐⭐

> 🎯 分值：10-15分 | 题型：全题型（综合题必出） | 难度：★★★★☆
> 近年趋势：新收入准则五步法是综合题热门考点，几乎年年出大题。特定交易（附退货权、合同变更、主要责任人vs代理人）高频考查。
>
> ⚠️ 收入和长股投、合并报表并称"中级实务三座大山"。

### 一、新收入准则五步法（核心框架）

```
第1步：识别与客户之间的合同
第2步：识别合同中的单独履约义务
第3步：确定交易价格
第4步：将交易价格分摊至各单独履约义务
第5步：在履行履约义务时（或完成时）确认收入
```

> 💡 **大白话**：签了什么合同 → 合同里有几件事要干 → 总共收多少钱 → 钱怎么分到每件事上 → 每件事干完了就确认收入

### 二、在某一时段内确认 vs 某一时点确认

**在某一时段内确认收入**（满足其一即可）：
1. 客户在企业履约的同时即取得并消耗了经济利益（如保洁服务）
2. 客户能够控制企业履约过程中在建的商品（如在客户土地上建房）
3. 企业履约过程中所产出的商品具有**不可替代用途**，且企业在整个合同期间内有权就已完成的部分收取款项

> 🔥 **不满足以上任何一条** → **在某一时点确认**（控制权转移时点）

**控制权转移的判断指标**：
- 企业有权收款
- 客户已取得法定所有权
- 已实物交付
- 客户已取得重大风险和报酬
- 客户已接受该商品

### 三、交易价格的确定

| 影响因素 | 处理 |
|:---|:---|
| **可变对价** | 期望值或最可能发生金额，受限于"极可能不会重大转回" |
| **重大融资成分** | 需要调整交易价格（除非付款期 ≤ 1年可不调） |
| **非现金对价** | 按公允价值计量 |
| **应付客户对价** | 冲减交易价格（如返利、折扣） |

### 四、特定交易（⭐⭐⭐高频考点）

#### ① 附有销售退回条款

```
销售时：
  按预期不会退货的部分确认收入
  预期会退回的部分 → 确认"预计负债"（退款负债）
  同时确认"应收退货成本"（收回商品的权利）

借：应收账款
    贷：主营业务收入（预计不退部分）
        预计负债—应付退货款（预计退回部分）
        应交税费—应交增值税（销项税额）
借：主营业务成本（预计不退部分的成本）
    应收退货成本（预计退回部分的成本）
    贷：库存商品
```

#### ② 附有质量保证条款

| 类型 | 处理 |
|:---|:---|
| **法定质保**（修理缺陷产品） | 不是单独履约义务 → 按或有事项确认预计负债 |
| **延保服务**（额外服务） | 是单独履约义务 → 分摊交易价格，服务期间分期确认收入 |

#### ③ 主要责任人 vs 代理人

| | 主要责任人 | 代理人 |
|:---|:---|:---|
| **核心区别** | 控制了商品/服务 | 只是安排别人提供 |
| **收入确认** | **总额法**（全额） | **净额法**（佣金） |
| **判断标准** | 承担主要风险、有定价权、先取得控制权 | 不承担存货风险、无定价权 |

> 💡 **大白话**：你是老板还是中间商？老板记全额收入，中间商只记手续费。

#### ④ 售后回购

| 类型 | 本质 | 处理 |
|:---|:---|:---|
| 回购价 ≥ 原售价 | **融资交易** | 不确认收入，收到款记金融负债 |
| 回购价 < 原售价 | **租赁交易** | 按租赁准则处理 |
| 客户有权要求回购 | 看客户是否有重大经济动因行权 | 有→同上；无→附退货权销售 |

### 📝 实战例题 · 附退货权销售

**题目**：甲公司2025年12月1日销售商品100件，单价10万元，成本6万元。合同约定30天内可退货。根据历史经验预计退货率20%。

```
不退部分：100 × 80% = 80件
退回部分：100 × 20% = 20件

借：应收账款                        1000（100×10）
    贷：主营业务收入                  800（80×10）
        预计负债—应付退货款           200（20×10）
        应交税费—应交增值税（销项）  （按全额计税，此处省略）

借：主营业务成本                      480（80×6）
    应收退货成本                      120（20×6）
    贷：库存商品                      600（100×6）
```

### 📝 实战例题 · 合同中包含多项履约义务

**题目**：甲公司与客户签订合同，销售A设备（单独售价80万）并提供2年维护服务（单独售价20万），合同总价90万元。

```
第2步：识别两项履约义务 — 设备销售 + 维护服务
第3步：交易价格 = 90万
第4步：按单独售价比例分摊
  分摊给设备 = 90 × 80/(80+20) = 72万
  分摊给服务 = 90 × 20/(80+20) = 18万
第5步：
  设备交付时确认收入72万
  服务在2年内按时段确认，每年9万
```

### 📝 仿真题

**【单选】** 甲公司是某电商平台的运营方，第三方商家在平台上销售商品，甲公司收取10%佣金。甲公司在该交易中是（ ）。
A. 主要责任人，按总额确认收入
B. 代理人，按净额确认收入
C. 主要责任人，按净额确认收入
D. 代理人，按总额确认收入

**答案：B** — 甲公司是平台方（中间商），不控制商品，是代理人，按净额（佣金）确认收入。

**【判断】** 附有销售退回条款的商品销售，企业应按全部商品的售价确认收入。（ ）

**答案：×** — 只能按预计不会退回的部分确认收入，预计退回部分确认预计负债。

## 第十四章 政府补助 ⭐⭐

> 🎯 分值：3-5分 | 题型：单选、多选、判断 | 难度：★★☆☆☆
> 近年趋势：两种核算方法（总额法/净额法）的区分和分录是高频考点。

### 一、政府补助的分类

| 类型 | 定义 | 典型例子 |
|:---|:---|:---|
| **与资产相关** | 用于购建长期资产 | 购买环保设备的财政拨款 |
| **与收益相关** | 补偿已发生/将发生的费用或损失 | 稳岗补贴、研发补助 |

> ⚠️ **不属于政府补助的情况**：
> - 政府作为企业所有者投入的资本 → 股东投资
> - 政府采购商品/服务 → 正常交易
> - 增值税即征即退/先征后返 → **属于**政府补助
> - 直接减免税款 → **不属于**

### 二、两种核算方法

| | 总额法 | 净额法 |
|:---|:---|:---|
| **核心思路** | 全额确认为收益 | 冲减相关成本/费用 |
| **与资产相关** | 收到时记递延收益，资产使用期间分期转入其他收益 | 收到时直接冲减资产账面价值 |
| **与收益相关** | 记其他收益/营业外收入 | 冲减相关成本费用 |

**总额法 — 与资产相关**：
```
收到补助：
借：银行存款
    贷：递延收益

资产使用期间分摊（与折旧同步）：
借：递延收益
    贷：其他收益
```

**净额法 — 与资产相关**：
```
收到补助：
借：银行存款
    贷：递延收益

购入资产时：
借：固定资产
    贷：银行存款
借：递延收益
    贷：固定资产（直接冲减资产账面价值）
```

**与收益相关**：
```
总额法：
  补偿以后期间的 → 先记递延收益，费用发生时转其他收益
  补偿已发生的   → 直接记其他收益或营业外收入

净额法：
  直接冲减相关成本费用
```

### 三、政府补助退回

```
总额法退回：
  冲减递延收益余额，不够部分记营业外支出

净额法退回：
  调整资产账面价值（补提折旧）
```

### 📝 仿真题

**【单选】** 企业收到用于补偿以后期间费用的政府补助，采用总额法核算时应贷记（ ）。
A. 营业外收入  B. 其他收益  C. 递延收益  D. 资本公积

**答案：C** — 补偿以后期间的先记递延收益，以后分期转入其他收益。

## 第十五章 非货币性资产交换 ⭐⭐

> 🎯 分值：3-5分 | 题型：单选、多选、计算 | 难度：★★★☆☆
> 近年趋势：是否具有商业实质 + 公允价值能否可靠计量的判断，决定用公允还是账面入账。

### 一、核心判断

```
                  具有商业实质？
                  /          \
                是             否
               /                \
    公允价值能可靠计量？      以账面价值计量
      /         \             （不确认损益）
    是           否
    /              \
以公允价值计量    以账面价值计量
（确认损益）     （不确认损益）
```

**商业实质的判断**（两条满足其一）：
1. 换入资产的未来现金流量在风险、时间、金额方面与换出资产**显著不同**
2. 换入资产与换出资产的**预计未来现金流量现值不同**，且差额与两者的公允价值相比是重大的

> 💡 **大白话**：换了之后经营有变化就有商业实质（如拿设备换专利），同类资产互换通常没有。

### 二、以公允价值计量（有商业实质+可靠计量）

```
换入资产成本 = 换出资产公允价值 + 支付的补价（或 - 收到的补价）+ 相关税费

换出资产公允价值与账面价值的差额 → 确认损益
  固定资产 → 资产处置损益
  存  货  → 主营业务收入/其他业务收入 + 结转成本
  无形资产 → 资产处置损益
```

### 三、以账面价值计量（无商业实质）

```
换入资产成本 = 换出资产账面价值 + 支付的补价（或 - 收到的补价）+ 相关税费

不确认损益！
```

### 📝 实战例题

**题目**：甲公司以一台设备（原价500万，累计折旧200万，公允价值350万）换入乙公司一项专利权（公允价值380万），甲公司另支付补价30万。具有商业实质，公允价值可靠计量。不考虑税费。

```
换入专利成本 = 设备公允350 + 补价30 = 380万

换出设备损益 = 公允350 - 账面(500-200) = 350 - 300 = 50万（利得）

借：无形资产                380
    累计折旧                200
    贷：固定资产              500
        银行存款               30
        资产处置损益            50
```

### 📝 仿真题

**【判断】** 非货币性资产交换不具有商业实质的，换出资产公允价值与其账面价值的差额应计入当期损益。（ ）

**答案：×** — 不具有商业实质时以账面价值计量，**不确认损益**。

## 第十六章 债务重组 ⭐⭐

> 🎯 分值：3-5分 | 题型：单选、多选、判断、计算 | 难度：★★☆☆☆
> 近年趋势：以资产清偿债务、将债务转为权益工具的会计处理是计算题重点。

### 一、债务重组的方式

| 方式 | 说明 |
|:---|:---|
| 以资产清偿债务 | 用存货、固定资产等抵债 |
| 将债务转为权益工具 | 债转股 |
| 修改其他条款 | 减免债务、延长期限、降低利率 |
| 以上方式的组合 | 混合 |

### 二、以资产清偿债务

**债务人（欠钱的）**：
```
借：应付账款（账面价值）
    贷：相关资产（按资产账面价值转出）
        应交税费（相关税费）
        其他收益—债务重组收益（差额）

注意：资产处置损益不单独确认，统一计入"其他收益"
```

**债权人（被欠钱的）**：
```
借：相关资产（按放弃债权的公允价值入账）
    坏账准备
    投资收益（差额，可借可贷）
    贷：应收账款
```

### 三、将债务转为权益工具（债转股）

**债务人**：
```
借：应付账款（账面价值）
    贷：股本（面值）
        资本公积—股本溢价（差额）
        其他收益—债务重组收益（差额）
```

**债权人**：
```
借：长期股权投资/其他权益工具投资（公允价值）
    坏账准备
    投资收益（差额，可借可贷）
    贷：应收账款
```

### 📝 实战例题

**题目**：甲公司欠乙公司500万元，甲公司以一批存货抵债（成本300万，公允价值350万，增值税率13%）。乙公司已计提坏账准备50万。

```
甲公司（债务人）：
  应付账款 = 500万
  存货账面 = 300万
  增值税销项 = 350 × 13% = 45.5万
  重组收益 = 500 - 300 - 45.5 = 154.5万

  借：应付账款            500
      贷：库存商品          300
          应交税费—销项税    45.5
          其他收益           154.5

乙公司（债权人）：
  放弃债权公允价值 = 350 + 45.5 = 395.5万（含税）
  → 存货入账 = 350万，进项税 = 45.5万
  
  借：库存商品              350
      应交税费—进项税        45.5
      坏账准备               50
      投资收益               54.5（500-50-395.5）
      贷：应收账款            500
```

### 📝 仿真题

**【单选】** 债务重组中，债务人以存货清偿债务，重组收益应计入（ ）。
A. 营业外收入  B. 其他业务收入  C. 其他收益  D. 资本公积

**答案：C** — 新准则下债务重组收益计入**其他收益**（不再是营业外收入）。

## 第十七章 所得税 ⭐⭐⭐

> 🎯 分值：8-12分 | 题型：全题型（计算题/综合题常考） | 难度：★★★★☆
> 近年趋势：暂时性差异的判断、递延所得税的确认和计量是综合题高频考点。本章从"零"学起，初级不涉及。
>
> ⚠️ 所得税会计是中级实务的"拦路虎"之一，必须理解透彻。

### 一、资产负债表债务法（核心思路）

```
核心公式：
  所得税费用 = 当期所得税 + 递延所得税费用

  当期所得税 = 应纳税所得额 × 税率
  递延所得税费用 = 递延所得税负债增加额 - 递延所得税资产增加额
```

> 💡 **大白话**：
> - "当期所得税"= 今年真要交给税务局的钱
> - "递延所得税"= 会计和税法有分歧，以后才需要多交/少交的钱

### 二、暂时性差异（全章核心！）

**暂时性差异 = 资产/负债的账面价值 vs 计税基础的差异**

#### 资产的计税基础

```
资产的计税基础 = 未来期间可以税前扣除的金额

大白话：税法还允许你以后扣多少钱
```

#### 负债的计税基础

```
负债的计税基础 = 账面价值 - 未来期间可以税前扣除的金额

大白话：这个负债里，以后能用来抵税的部分要扣掉
```

### 三、两种暂时性差异

| | 应纳税暂时性差异 | 可抵扣暂时性差异 |
|:---|:---|:---|
| **资产** | 账面价值 > 计税基础 | 账面价值 < 计税基础 |
| **负债** | 账面价值 < 计税基础 | 账面价值 > 计税基础 |
| **含义** | 以后要**多交税** | 以后可以**少交税** |
| **确认** | **递延所得税负债**（DTL） | **递延所得税资产**（DTA） |
| **记忆** | 资产大了以后多交 | 资产小了以后少交 |

> 🔥 **速记口诀**：资产账面大于税基→交，资产账面小于税基→抵。负债反过来。

### 四、常见暂时性差异汇总表

| 项目 | 账面价值 | 计税基础 | 差异类型 | 递延所得税 |
|:---|:---|:---|:---|:---|
| 固定资产（会计折旧>税法） | 较小 | 较大 | 可抵扣 | DTA |
| 固定资产（会计折旧<税法） | 较大 | 较小 | 应纳税 | DTL |
| 交易性金融资产公允价值上升 | 增大 | 不变（取得成本） | 应纳税 | DTL |
| 交易性金融资产公允价值下降 | 减小 | 不变 | 可抵扣 | DTA |
| 存货计提跌价准备 | 减小 | 不变（成本） | 可抵扣 | DTA |
| 预计负债（产品质保） | 增大 | 0（实际发生时才能扣） | 可抵扣 | DTA |
| 国债利息收入 | — | — | **非暂时性差异**（永久免税） | 不确认 |
| 违法罚款 | — | — | **非暂时性差异**（永久不可扣） | 不确认 |

> ⚠️ **永久性差异 vs 暂时性差异**：
> - 永久性差异（如国债利息免税、罚款不可扣）→ **不确认递延所得税**
> - 暂时性差异（如折旧差异、公允价值变动）→ **确认递延所得税**

### 五、不确认递延所得税的特殊情况

以下情况虽产生暂时性差异但**不确认递延所得税**：
1. 商誉的初始确认
2. 非企业合并中，交易既不影响会计利润也不影响应纳税所得额
3. 与子公司/联营/合营相关的应纳税暂时性差异，能控制转回且预计不会转回

### 六、会计分录

```
确认递延所得税资产（DTA）：
借：递延所得税资产
    贷：所得税费用（影响损益的差异）
        其他综合收益（因OCI产生的差异）

确认递延所得税负债（DTL）：
借：所得税费用
    贷：递延所得税负债
```

### 📝 实战例题 · 所得税完整计算

**题目**：甲公司2025年利润总额1000万元，税率25%。以下事项需要纳税调整：
1. 国债利息收入50万元
2. 违法罚款支出30万元
3. 计提存货跌价准备80万元（税法不允许扣除）
4. 交易性金融资产公允价值上升60万元（税法不确认）

```
第1步：计算应纳税所得额
  利润总额                              1000
  - 国债利息（永久免税，调减）           -50
  + 罚款（永久不可扣，调增）             +30
  + 存货跌价准备（暂时性，调增）         +80
  - 公允价值上升（暂时性，调减）         -60
  = 应纳税所得额                        1000

第2步：当期所得税
  1000 × 25% = 250万

第3步：递延所得税
  存货跌价80万 → 可抵扣差异 → DTA = 80 × 25% = 20万
  公允上升60万 → 应纳税差异 → DTL = 60 × 25% = 15万
  递延所得税费用 = DTL增加 - DTA增加 = 15 - 20 = -5万

第4步：所得税费用
  = 当期250 + 递延(-5) = 245万

分录：
借：所得税费用              245
    递延所得税资产            20
    贷：应交税费—应交所得税   250
        递延所得税负债         15
```

### 📝 仿真题

**【单选】** 企业因违反税法规定被罚款100万元，该项罚款（ ）。
A. 产生可抵扣暂时性差异
B. 产生应纳税暂时性差异
C. 不产生暂时性差异
D. 产生递延所得税资产

**答案：C** — 罚款属于永久性差异（永远不能税前扣除），不产生暂时性差异，不确认递延所得税。

**【判断】** 企业应对所有的可抵扣暂时性差异确认递延所得税资产。（ ）

**答案：×** — 应以未来期间**很可能取得足够的应纳税所得额**为前提，才能确认DTA。如果以后可能亏损赚不到钱，就不能确认。

## 第十八章 外币折算 ⭐

> 🎯 分值：2-3分 | 题型：单选、判断 | 难度：★★☆☆☆
> 近年趋势：外币交易的汇兑差额处理、外币报表折算方法偶尔出1-2道选择题。

### 一、外币交易的记账方法

**初始确认**：按交易发生日的即期汇率折算。

**资产负债表日**：

| 项目 | 折算汇率 | 汇兑差额处理 |
|:---|:---|:---|
| **货币性项目**（外币现金、应收/应付等） | 资产负债表日**即期汇率** | → **财务费用** |
| **非货币性项目—历史成本** | 交易日汇率（不变） | 不产生差额 |
| **非货币性项目—公允价值** | 公允价值确定日汇率 | → 公允价值变动损益/OCI |

> 💡 **大白话**：钱和应收应付用最新汇率重算，差额记财务费用。固定资产、存货等实物不重算。

### 二、外币财务报表折算

| 报表项目 | 折算汇率 |
|:---|:---|
| 资产、负债 | **资产负债表日即期汇率** |
| 所有者权益（实收资本等） | **发生时的历史汇率** |
| 收入、费用 | 交易发生日汇率（或近似的**平均汇率**） |
| **折算差额** | → **其他综合收益** |

### 📝 实战例题

**题目**：甲公司记账本位币为人民币，12月1日销售商品取得外币应收账款100万美元，当日即期汇率6.50。12月31日即期汇率6.55。

```
12月1日确认：
借：应收账款    650万（100×6.50）
    贷：主营业务收入  650万

12月31日调整：
  新金额 = 100 × 6.55 = 655万
  汇兑收益 = 655 - 650 = 5万

借：应收账款    5
    贷：财务费用  5（汇兑收益冲减财务费用）
```

### 📝 仿真题

**【单选】** 外币货币性项目在资产负债表日产生的汇兑差额应计入（ ）。
A. 其他综合收益  B. 资本公积  C. 财务费用  D. 管理费用

**答案：C** — 外币货币性项目的汇兑差额计入**财务费用**。

**【判断】** 外币财务报表折算差额应计入当期财务费用。（ ）

**答案：×** — 外币财务报表折算差额计入**其他综合收益**，不是财务费用。注意区分：交易的汇兑差额→财务费用；报表折算差额→OCI。
