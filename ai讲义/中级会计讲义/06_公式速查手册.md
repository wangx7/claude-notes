## 一、会计实务 · 核心分录速查

### 存货

```
购入：借：原材料 / 应交税费—应交增值税(进项)  贷：银行存款
发出计价：先进先出法、加权平均法、个别计价法
期末：成本与可变现净值孰低
减值：借：资产减值损失  贷：存货跌价准备
```

### 固定资产

```
购入：借：固定资产  贷：银行存款
折旧：借：制造费用/管理费用  贷：累计折旧
处置：转入清理→收入→费用→结转净损益（资产处置损益/营业外）
```

### 无形资产

```
研发支出：研究阶段→费用化；开发阶段（满足5条件）→资本化
借：研发支出—费用化/资本化支出  贷：银行存款等
达到预定用途：借：无形资产  贷：研发支出—资本化支出
```

### 长期股权投资

```
成本法（控制）：
  取得：借：长投  贷：银行存款
  分红：借：应收股利  贷：投资收益

权益法（重大影响/共同控制）：
  取得：同上
  被投资方盈利：借：长投—损益调整  贷：投资收益
  被投资方亏损：反向
  被投资方分红：借：应收股利  贷：长投—损益调整
  其他综合收益：借：长投—其他综合收益  贷：其他综合收益
```

### 金融资产三分类

```
交易性金融资产：公允价值变动→当期损益
其他债权投资：公允价值变动→其他综合收益（可回转）
其他权益工具投资：公允价值变动→其他综合收益（不可回转）
```

### 收入（五步法）

```
1.识别合同 → 2.识别履约义务 → 3.确定交易价格 →
4.分摊交易价格 → 5.确认收入（时点/时段）

时点确认：控制权转移时（交付、验收等）
时段确认：产出法或投入法（建造合同等）
```

### 所得税

```
递延所得税资产（DTA）= 可抵扣暂时性差异 × 税率
递延所得税负债（DTL）= 应纳税暂时性差异 × 税率

所得税费用 = 当期所得税 + 递延所得税费用
           = 应交所得税 + (DTL增加 - DTA增加)
```

### 合并报表抵销分录

```
① 长投 vs 子公司权益：
借：股本/资本公积/盈余公积/未分配利润/商誉
  贷：长投 / 少数股东权益

② 投资收益 vs 利润分配：
借：投资收益/少数股东损益/未分配利润—年初
  贷：提取盈余公积/对所有者分配/未分配利润—年末

③ 内部交易抵销：
借：营业收入  贷：营业成本/存货
```

## 二、财务管理 · 全部公式速查

### 货币时间价值

```
复利终值：F = P×(1+i)^n
复利现值：P = F×(1+i)^(-n)
普通年金终值：F = A×(F/A,i,n)
普通年金现值：P = A×(P/A,i,n)
预付年金：在普通年金基础上 ×(1+i)
永续年金现值：P = A/i
```

### 风险与收益

```
期望收益率：E(R) = ΣPi×Ri
标准差：σ = √[ΣPi×(Ri-E(R))²]
变异系数：V = σ/E(R)
CAPM：R = Rf + β×(Rm-Rf)
```

### 资本成本

```
债务成本：Kd = i×(1-T)/(1-f)
普通股（股利模型）：Ks = D₁/P₀ + g
普通股（CAPM）：Ks = Rf + β(Rm-Rf)
WACC = ΣWj×Kj
```

### 杠杆系数

```
DOL = M/(M-F) = M/EBIT
DFL = EBIT/(EBIT-I-D/(1-T))
DTL = DOL × DFL
```

### 投资决策

```
NCF = 收入×(1-T) - 付现成本×(1-T) + 折旧×T
NPV = ΣNCF/(1+i)^t - 初始投资
IRR：令NPV=0求解的i
年金净流量 = NPV/(P/A,i,n)
```

### 营运资金

```
最佳现金持有量：Q* = √(2TF/K)
经济订货量：Q* = √(2KD/Kc)
放弃折扣成本 = 折扣率/(1-折扣率) × 360/(信用期-折扣期)
应收账款机会成本 = 日销售额×收现期×变动成本率×资本成本率
```

### 本量利分析

```
保本点销售量 = 固定成本/单位边际贡献
保本点销售额 = 固定成本/边际贡献率
保利点销售量 = (固定成本+目标利润)/单位边际贡献
安全边际率 = (实际销量-保本销量)/实际销量
```

### 杜邦分析

```
ROE = 营业净利率 × 总资产周转率 × 权益乘数
    = (净利润/收入) × (收入/资产) × (资产/权益)
```

### 股利政策

```
剩余股利 = 净利润 - 投资额×权益比例
定金上限 = 主合同标的额×20%
```

## 三、经济法 · 数字速记表

### 时间类

| 数字 | 内容 |
|:---|:---|
| **3年** | 普通诉讼时效 |
| **20年** | 最长诉讼时效 |
| **1个月** | 无权代理催告追认期 |
| **30日** | LP对外转让份额通知期；不定期合伙退伙通知期 |
| **6个月** | 商业汇票最长付款期限 |
| **10日** | 汇票到期后提示付款期 |
| **20年** | 租赁合同最长期限 |
| **2年** | 买卖合同标的物质量异议最长期限 |
| **5年** | 有限公司出资期限上限（2024新规） |
| **4个月** | 年度报告披露期限 |
| **2个月** | 中期报告披露期限；留置权宽限期 |

### 比例类

| 数字 | 内容 |
|:---|:---|
| **5%** | 上市公司股东持股变动披露线 |
| **30%** | 要约收购触发线 |
| **10%** | 法定盈余公积提取比例 |
| **50%** | 法定盈余公积累计上限（达注册资本50%可不再提） |
| **20%** | 定金上限比例 |
| **2/3** | 特别决议表决权比例 |
| **14%** | 职工福利费扣除上限 |
| **2%** | 工会经费扣除上限 |
| **8%** | 职工教育经费扣除上限 |
| **12%** | 公益捐赠扣除上限 |
| **15%** | 广告宣传费扣除上限 |
| **60%+5‰** | 业务招待费双限额 |

### 增值税税率

```
13% → 货物、加工修理修配、有形动产租赁
9%  → 不动产、交通运输、建筑、农产品
6%  → 金融、现代服务、生活服务
0%  → 出口
```

### 企业所得税税率

```
25% → 基本税率
15% → 高新技术企业
5%  → 小型微利（实际）
```
