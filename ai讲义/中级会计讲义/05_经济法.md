## 第一章 总论 ⭐

> 🎯 分值：3-5分 | 题型：单选、多选、判断 | 难度：★☆☆☆☆
> 近年趋势：法律行为、代理、诉讼时效是高频客观题考点。

### 一、经济法的渊源

| 渊源 | 制定机关 | 举例 |
|:---|:---|:---|
| 宪法 | 全国人大 | 最高法律效力 |
| 法律 | 全国人大及常委会 | 公司法、合伙企业法 |
| 行政法规 | 国务院 | 企业所得税法实施条例 |
| 地方性法规 | 地方人大 | 各省实施办法 |
| 部门规章 | 国务院部委 | 财政部发布的办法 |

### 二、法律行为

#### 法律行为的有效要件

```
1. 行为人具有相应的民事行为能力
2. 意思表示真实
3. 不违反法律、行政法规的强制性规定
4. 不违背公序良俗
```

#### 无效、可撤销、效力待定

| 类型 | 情形 | 法律后果 |
|:---|:---|:---|
| **无效** | 违法、违背公序良俗、恶意串通、虚假意思表示 | 自始无效，不可补正 |
| **可撤销** | 重大误解、欺诈、胁迫、显失公平 | 撤销前有效，撤销后自始无效 |
| **效力待定** | 限制行为能力人超出能力范围、无权代理、无权处分 | 等待追认 |

> 🔥 **记忆口诀**：
> - 无效 → "违法的、假的、串通的"——最严重
> - 可撤销 → "被骗的、被迫的、搞错的"——受害人有选择权
> - 效力待定 → "没权的、小孩做的"——等大人/本人点头

### 三、代理

```
代理的种类：
  委托代理：基于委托授权
  法定代理：基于法律直接规定（如父母代理未成年子女）

无权代理：
  没有代理权、超越代理权、代理权终止后仍以代理人身份行事
  → 效力待定，等本人追认
  
  善意相对人：可以催告本人追认（1个月内不表态视为拒绝追认）
  
表见代理（⭐重要）：
  无权代理人具有"有权代理的外观"，善意相对人有理由相信
  → 该代理行为有效！（保护善意第三人）
```

### 四、诉讼时效（⭐⭐高频考点）

```
普通诉讼时效：3年（从知道或应当知道权利受侵害之日起）
最长诉讼时效：20年（从权利被侵害之日起，不适用中止中断）

⚠️ 诉讼时效届满的后果：
  不是权利消灭！而是丧失"胜诉权"（法院不主动适用）
  义务人自愿履行的，不得请求返还

诉讼时效的中止：
  最后6个月内，因不可抗力等障碍不能行使 → 暂停计算
  障碍消除后继续计算

诉讼时效的中断（⭐重要）：
  起诉、请求、义务人同意履行 → 重新计算！
  
💡 中止 = 暂停（按了暂停键）
   中断 = 归零重来（按了重置键）
```

### 📝 仿真题

**【单选】** 下列各项中，属于可撤销法律行为的是（ ）。
A. 恶意串通损害他人利益  B. 以虚假意思表示实施的
C. 因重大误解实施的  D. 违反法律强制性规定的

**答案：C** — A、B、D都是无效。C重大误解是可撤销。

**【判断】** 诉讼时效期间届满，权利人丧失的是实体权利。（ ）

**答案：×** — 丧失的是**胜诉权**（程序性权利），实体权利并不消灭。

**【单选】** 下列关于表见代理的说法中，正确的是（ ）。
A. 表见代理属于有权代理  B. 表见代理的法律后果由代理人承担
C. 表见代理对本人产生有权代理的效力  D. 表见代理中相对人是恶意的

**答案：C** — 表见代理本质是无权代理，但对善意相对人产生有权代理的效力，后果由本人承担。

## 第二章 公司法律制度 ⭐⭐⭐

> 🎯 分值：10-15分 | 题型：全题型（简答题/综合题高频） | 难度：★★★★☆
> 近年趋势：公司设立条件、股东权利、董监高制度、股权转让是必考重点。

### 一、公司的分类

| 分类标准 | 类型 | 特点 |
|:---|:---|:---|
| 股东责任 | **有限责任公司** | 1-50人，不公开发行股份 |
| | **股份有限公司** | 2-200人发起，可公开发行 |
| 信用基础 | 人合公司 | 基于股东信任（合伙） |
| | 资合公司 | 基于资本（股份公司） |
| | 人资兼合 | **有限公司**（兼具两者） |

### 二、有限责任公司（⭐⭐⭐）

#### 设立条件

```
1. 股东人数：1人以上50人以下（含一人公司）
2. 注册资本：认缴制（无最低限额，特殊行业除外）
3. 有公司章程
4. 有公司名称和组织机构
5. 有住所

⚠️ 一人有限公司的特殊规定：
  - 一个自然人只能设立一个一人公司
  - 一人公司必须在营业执照中载明
  - 不能证明财产独立的 → 对公司债务承担连带责任
```

#### 股东出资

```
出资形式：
  ✅ 货币、实物、知识产权、土地使用权、股权、债权等
  ❌ 劳务、信用、自然人姓名、商誉不能出资

出资期限：认缴制，章程约定的期限内缴足
  ⚠️ 2024年新规：有限公司出资期限不得超过5年

股东出资不实的后果：
  对公司：补缴 + 赔偿
  对其他股东：违约责任
  对债权人：在未出资本息范围内承担补充赔偿责任
```

#### 股权转让（⭐⭐⭐高频考点）

```
内部转让：股东之间自由转让（无需其他股东同意）

对外转让（新公司法2024修订）：
  通知其他股东即可，无需同意
  其他股东有优先购买权（同等条件下）
  
优先购买权：
  书面通知后30日内不答复 → 视为放弃优先购买权
  两个以上股东主张优先购买 → 协商；协商不成按出资比例
  
💡 2024新规简化：取消了"过半数同意"的要求，对外转让只需通知
```

### 三、股份有限公司

#### 设立方式

| 方式 | 特点 |
|:---|:---|
| **发起设立** | 发起人认购全部股份（2人以上200人以下） |
| 募集设立 | 发起人认购部分+向社会公开募集 |

```
股份有限公司特点：
  资本总额 → 等额股份
  股份发行 → 同股同价
  每股面值 → 人民币1元（也可无面值）
  
上市条件（了解）：
  公开发行股份达到总股本25%以上（4亿以上的10%以上）
```

### 四、公司治理结构

```
股东（大）会：最高权力机构
  ├── 董事会：决策执行机构
  │     └── 经理：日常经营
  └── 监事会：监督机构

⚠️ 不相容职务：
  董事、高管 ≠ 监事（不能兼任）
  董事长 ≠ 经理（可以兼任）
```

#### 股东会决议

| 决议类型 | 有限公司 | 股份公司 |
|:---|:---|:---|
| **普通决议** | 代表过半数表决权通过 | 出席会议过半数通过 |
| **特别决议** | 代表2/3以上表决权通过 | 出席会议2/3以上通过 |

```
特别决议事项（⭐必记）：
  1. 修改公司章程
  2. 增减注册资本
  3. 合并、分立、解散
  4. 变更公司形式
  
💡 记忆口诀：涉及"公司生死大事"的都需要特别决议（2/3）
```

#### 董事、监事、高管的义务

```
忠实义务（不损害公司利益）：
  - 不得挪用公司资金
  - 不得将公司资金借贷给他人或以公司资产为他人提供担保
  - 不得自营或为他人经营与公司同类的业务（竞业禁止）
  - 不得利用关联关系损害公司利益

勤勉义务（尽职尽责）：
  合理注意 + 为公司最大利益行事
```

### 📝 仿真题

**【单选】** 有限责任公司的股东向股东以外的人转让股权时，下列说法正确的是（ ）。
A. 必须经其他股东过半数同意  B. 应当书面通知其他股东
C. 其他股东无优先购买权  D. 无需通知其他股东

**答案：B** — 2024新公司法规定对外转让只需书面通知（不再要求过半数同意），其他股东有优先购买权。

**【多选】** 下列各项中，属于股东会特别决议事项的有（ ）。
A. 修改公司章程  B. 选举董事
C. 公司合并  D. 增加注册资本

**答案：ACD** — B选举董事是普通决议事项。A、C、D都是"生死大事"，需2/3以上。

**【判断】** 一个自然人可以投资设立多个一人有限责任公司。（ ）

**答案：×** — 一个自然人只能设立**一个**一人有限责任公司。

## 第三章 合伙企业法律制度 ⭐⭐

> 🎯 分值：5-8分 | 题型：单选、多选、判断、简答 | 难度：★★★☆☆
> 近年趋势：普通合伙vs有限合伙的区别、入伙退伙、合伙人的权利义务是高频考点。

### 一、合伙企业的类型

| | 普通合伙 | 特殊普通合伙 | 有限合伙 |
|:---|:---|:---|:---|
| **责任** | 全体无限连带 | 过错合伙人无限，其他有限 | GP无限+LP有限 |
| **合伙人** | 2人以上 | 2人以上（专业服务机构） | GP≥1 + LP≥1，总数2-50人 |
| **执行事务** | 全体均可 | 全体均可 | **仅GP执行，LP不得执行** |
| **出资** | 可以劳务出资 | 可以劳务出资 | **LP不得以劳务出资** |

> 🔥 **核心区分**：GP（普通合伙人）= 管事+无限责任；LP（有限合伙人）= 出钱+有限责任

### 二、普通合伙企业

#### 合伙人的权利义务

```
合伙事务执行：
  全体合伙人共同执行，或委托1人以上执行
  重大事项：全体合伙人一致同意
  日常事项：可由执行合伙人决定

竞业禁止（⭐重要）：
  普通合伙人 → 不得自营或与他人合作经营与本企业相竞争的业务
  除非经全体合伙人一致同意

财产份额转让：
  内部转让：通知其他合伙人即可
  对外转让：须经其他合伙人一致同意
  其他合伙人有优先购买权
```

#### 入伙与退伙

```
入伙：
  须经全体合伙人一致同意
  新合伙人对入伙前的债务承担无限连带责任（⭐易错！）

退伙：
  协议退伙：按协议约定
  通知退伙：不定期合伙，提前30日通知
  当然退伙：死亡、丧失行为能力、破产等
  除名：未履行义务、因故意或重大过失给企业造成损失等

退伙人对退伙前的债务承担无限连带责任
```

> ⚠️ **易错点**：新入伙的人对"入伙前"的老债务也要承担连带责任！退伙的人对"退伙前"的老债务仍然承担连带责任！

### 三、有限合伙企业（⭐⭐高频对比考点）

```
有限合伙人（LP）的特殊规定：
  ❌ 不得以劳务出资
  ❌ 不得执行合伙事务
  ❌ 不得代表合伙企业对外交易
  ✅ 可以与本企业进行交易（普通合伙人不行！）
  ✅ 可以自营或与他人合作经营同类业务（无竞业禁止！）
  ✅ 可以将财产份额出质（普通合伙人须一致同意才能出质）

💡 理解：LP只出钱不管事，所以限制少、自由多
         GP管事又负无限责任，所以限制多、自由少
```

#### GP与LP的核心对比（⭐⭐⭐必背表格）

| 事项 | GP（普通合伙人） | LP（有限合伙人） |
|:---|:---|:---|
| 责任 | 无限连带 | 以出资额为限 |
| 出资 | 可以劳务 | **不可**劳务 |
| 执行事务 | 可以 | **不可** |
| 竞业禁止 | **有**（不可同业竞争） | **无**（可以同业） |
| 与本企业交易 | **不可**（除非一致同意） | **可以** |
| 财产份额出质 | 须一致同意 | 除非协议约定不可 |
| 对外转让份额 | 须一致同意 | 提前30日通知即可 |

### 📝 仿真题

**【单选】** 有限合伙企业中，有限合伙人可以（ ）。
A. 以劳务出资  B. 执行合伙事务
C. 与本企业进行交易  D. 代表合伙企业对外签约

**答案：C** — LP可以与本企业交易，这是LP的特权。A、B、D都是LP不能做的。

**【多选】** 下列关于普通合伙企业入伙的说法中，正确的有（ ）。
A. 入伙须经全体合伙人一致同意
B. 新合伙人对入伙前的债务不承担责任
C. 入伙协议另有约定的除外
D. 新合伙人对入伙前的债务承担无限连带责任

**答案：AD** — 入伙须一致同意(A对)，新人对老债务也要连带(D对)。B错，C不存在这种"另有约定"。

**【判断】** 有限合伙人可以自营与有限合伙企业相竞争的业务。（ ）

**答案：✅** — LP没有竞业禁止义务，可以自营同类业务。

## 第四章 物权法律制度 ⭐⭐

> 🎯 分值：5-8分 | 题型：单选、多选、判断 | 难度：★★★☆☆
> 近年趋势：物权变动规则、担保物权（抵押vs质押vs留置）的对比是高频考点。

### 一、物权的类型

```
物权体系：
├── 所有权：占有、使用、收益、处分（最完整）
├── 用益物权：土地承包经营权、建设用地使用权、居住权、地役权
└── 担保物权：抵押权、质权、留置权
```

### 二、物权变动

#### 不动产物权变动 → 登记生效

```
不动产（房屋、土地）：
  设立、变更、转让、消灭 → 经登记发生效力
  未经登记不发生物权效力（合同可以有效，但物权不转移）

💡 买房不过户 = 合同有效但房子不是你的
```

#### 动产物权变动 → 交付生效

```
动产（汽车、设备等）：
  转让 → 自交付时发生效力

特殊交付方式：
  现实交付：实际转移占有
  简易交付：买方已经占有（如先租后买）
  指示交付：指示第三人交付
  占有改定：出卖人继续占有（如卖后回租）
  
⚠️ 船舶、航空器、机动车 → 交付生效，登记对抗
   即：不登记也生效，但不能对抗善意第三人
```

### 三、担保物权（⭐⭐⭐核心对比）

| | **抵押权** | **质权** | **留置权** |
|:---|:---|:---|:---|
| **占有** | 不转移占有 | **转移占有** | **已合法占有** |
| **标的物** | 不动产+动产 | 动产+权利 | **仅动产** |
| **设立** | 合同+登记（不动产）/合同（动产） | **交付** | 法定（无需约定） |
| **本质** | 物还在你手里 | 物交给债权人 | 债权人已经拿着你的物 |

> 🔥 **记忆口诀**：
> - 抵押 = "不搬家"（东西还在债务人手上）
> - 质押 = "搬过去"（东西交给债权人）
> - 留置 = "不还了"（债权人已经拿着，你不付钱我不还）

#### 抵押权

```
可以抵押的：
  ✅ 建筑物、建设用地使用权
  ✅ 生产设备、原材料、半成品、产品
  ✅ 正在建造的建筑物、船舶、航空器
  ✅ 交通运输工具

不得抵押的（⭐必记）：
  ❌ 土地所有权
  ❌ 宅基地使用权（原则上）
  ❌ 学校、幼儿园、医疗机构等公益设施
  ❌ 所有权、使用权不明或有争议的财产
  ❌ 依法被查封、扣押、监管的财产

抵押权的实现：
  债务到期未清偿 → 协商折价/拍卖/变卖
  同一财产上有多个抵押权 → 登记在先的优先
```

#### 质权

```
动产质权：自交付质押财产时设立
权利质权：
  ✅ 汇票、支票、本票、存款单
  ✅ 基金份额、股权（登记设立）
  ✅ 应收账款（登记设立）
  ✅ 知识产权中的财产权

质权人在债务到期前：
  ❌ 不得擅自使用、处分质押财产
  ✅ 有权收取质押财产的孳息
```

#### 留置权

```
留置权特点：
  法定担保物权（不需要约定，法律直接规定）
  仅适用于动产
  
典型场景：修车不付钱 → 修理厂可以留置你的车

留置权 > 抵押权 > 质权（留置权优先级最高！）

留置权人应给债务人2个月以上的宽限期
```

### 📝 仿真题

**【单选】** 下列财产中，不得抵押的是（ ）。

## 第五章 合同法律制度 ⭐⭐⭐

> 🎯 分值：15-20分 | 题型：全题型（简答题/综合题必考） | 难度：★★★★★
> 近年趋势：合同法是经济法分值最高的章节！要约承诺、合同履行、违约责任、买卖合同、借款合同、租赁合同是必考重点。

### 一、合同的订立

#### 要约与要约邀请

| | **要约** | **要约邀请** |
|:---|:---|:---|
| 定义 | 希望与他人订立合同的**具体**意思表示 | 希望他人向自己**发出要约** |
| 效力 | 到达受要约人时**生效** | 不产生合同约束力 |
| 举例 | 明确价格、数量的报价单 | 招标公告、商业广告、价目表 |

```
要约的条件（⭐必记）：
  1. 内容具体确定（有标的、数量等核心条款）
  2. 表明一经承诺即受约束
  
⚠️ 商业广告一般是要约邀请
   但内容符合要约条件的广告 = 要约（如"先到先得，售完为止"）
   
要约的撤回与撤销：
  撤回：要约到达前或同时到达（还没生效就收回）
  撤销：要约到达后、承诺发出前（已生效但后悔了）
  
不可撤销的要约：
  ① 确定了承诺期限
  ② 明示不可撤销
  ③ 受要约人有理由认为不可撤销并做了准备
```

#### 承诺

```
承诺的条件：
  1. 由受要约人作出
  2. 同意要约的内容（实质性变更 = 新要约，不是承诺）
  3. 在要约有效期内到达

实质性变更（变了等于没承诺）：
  标的、数量、质量、价款、履行期限地点方式、违约责任、争议解决
  
非实质性变更：对要约内容的微小补充 → 仍然构成承诺（除非要约人及时反对）

合同成立时间 = 承诺到达要约人时
```

### 二、合同的效力

```
有效合同：满足全部有效要件
无效合同：同第一章（违法、虚假、恶意串通）
可撤销合同：同第一章（欺诈、胁迫、重大误解、显失公平）
效力待定合同：
  ① 限制行为能力人超出范围
  ② 无权代理
  ③ 无权处分（善意取得除外）
```

#### 格式条款（⭐高频考点）

```
格式条款：一方预先拟定、重复使用、未与对方协商的条款

无效的格式条款：
  ① 不合理地免除己方责任
  ② 不合理地加重对方责任
  ③ 排除对方主要权利
  
提示说明义务：
  提供格式条款的一方应当采取合理方式提示对方注意
  未履行提示义务 → 对方可主张该条款不成为合同内容

解释规则：
  对格式条款有两种以上理解 → 作出不利于提供方的解释
  格式条款 vs 非格式条款冲突 → 采用非格式条款
```

### 三、合同的履行

#### 抗辩权（⭐⭐⭐必考）

| 抗辩权 | 适用情形 | 效果 |
|:---|:---|:---|
| **同时履行抗辩权** | 双方同时履行，一方未履行 | 另一方有权拒绝 |
| **先履行抗辩权** | 先履行方未履行 | 后履行方有权拒绝 |
| **不安抗辩权** | 先履行方有确切证据证明后履行方丧失履行能力 | 先履行方可中止履行 |

```
不安抗辩权的适用条件（⭐必记）：
  先履行方发现后履行方有以下情形：
  ① 经营状况严重恶化
  ② 转移财产、抽逃资金以逃避债务
  ③ 丧失商业信誉
  ④ 有丧失或可能丧失履行能力的其他情形

  行使不安抗辩权后：
  → 应当及时通知对方
  → 对方提供担保的，应当恢复履行
  → 对方在合理期限内未恢复履行能力且未提供担保 → 可以解除合同
```

### 四、合同的保全

```
代位权（⭐重要）：
  债务人怠于行使到期债权，损害债权人利益
  → 债权人可以自己的名义向法院请求代位行使

  条件：
  ① 债权人对债务人的债权合法到期
  ② 债务人怠于行使对次债务人的到期债权
  ③ 债务人的怠于行使损害了债权人利益

撤销权：
  债务人以下行为损害债权人利益的，债权人可以请求法院撤销：
  ① 无偿转让/放弃财产
  ② 以明显不合理的低价转让财产（受让人知情）
  ③ 放弃到期债权
  ④ 恶意延长到期债权的履行期限

  撤销权行使期限：
  知道或应当知道之日起1年内
  最长5年（自行为发生之日起）
```

### 五、合同的解除

```
约定解除：双方协商一致
法定解除（⭐必记）：
  ① 因不可抗力致使不能实现合同目的
  ② 一方明确表示不履行（预期违约）
  ③ 一方迟延履行，经催告后合理期限内仍未履行
  ④ 一方迟延或有其他违约行为致使合同目的不能实现
  
解除权行使：通知对方即生效（不需要法院判决）
解除权行使期限：知道或应当知道之日起1年内
```

### 六、违约责任（⭐⭐⭐）

```
违约责任的承担方式：
  1. 继续履行（强制履行）
  2. 补救措施（修理、更换、退货）
  3. 赔偿损失
  4. 支付违约金
  5. 定金罚则

违约金 vs 定金（⭐易混淆）：
  违约金：合同约定的违约赔偿数额
  定金：预先支付的担保金额
  
  两者不能同时适用！当事人只能选其一。

定金规则（⭐⭐⭐必背）：
  收定金方违约 → 双倍返还定金
  交定金方违约 → 无权要求返还定金
  定金上限：不超过主合同标的额的20%

💡 定金 ≠ 订金！
   定金 = 有法律效力的担保
   订金 = 只是预付款，没有罚则效力
```

### 七、典型合同（⭐⭐⭐高频考点）

#### 买卖合同

```
标的物风险转移规则（⭐⭐⭐必考）：
  一般规则：标的物毁损灭失的风险，自交付时转移
  
  具体情形：
  ① 买方自提：提货时风险转移
  ② 卖方送货：到达指定地点时风险转移
  ③ 需要运输：交第一承运人时风险转移
  ④ 在途货物：合同成立时风险转移
  
💡 核心：交付 = 风险转移（不管所有权是否转移）

标的物检验：
  约定检验期的 → 在检验期内通知质量异常
  没约定的 → 合理期限内通知，最长不超过2年
  未在期限内通知 → 视为质量合格
```

#### 借款合同

```
自然人之间的借款合同：自贷款人提供借款时生效（实践合同）
金融机构借款合同：自合同成立时生效（诺成合同）

利率规定（⭐重要）：
  借款利息不得预先在本金中扣除
  预先扣除的 → 按实际借款数额计算利息
  
  民间借贷利率上限：
  合同成立时一年期LPR的4倍
```

#### 租赁合同

```
租赁期限：最长不超过20年（超过部分无效）
  不定期租赁：双方随时可以解除（提前合理期限通知）

承租人的权利：
  ✅ 转租权（经出租人同意）→ 未经同意可解除
  ✅ 优先购买权（出租人出售时）
  ✅ 买卖不破租赁（房屋卖了，租赁合同继续有效）

买卖不破租赁（⭐重要）：
  租赁物所有权变动 → 不影响租赁合同的效力
  新买家必须继续履行原租赁合同
```

## 第六章 金融法律制度 ⭐⭐⭐

> 🎯 分值：10-15分 | 题型：全题型（简答题/综合题高频） | 难度：★★★★☆
> 近年趋势：票据法（汇票的出票、背书、承兑、保证）和证券法（上市、信息披露）是必考重点。

### 一、票据法律制度

#### 票据的种类

| 票据 | 出票人 | 付款人 | 特点 |
|:---|:---|:---|:---|
| **汇票** | 出票人 | 承兑人/付款人 | 最重要，考试重点 |
| **本票** | 出票人（银行） | 出票人自己 | 自付票据 |
| **支票** | 出票人 | 银行 | 见票即付 |

```
汇票分类：
  商业汇票（商业承兑/银行承兑）→ 考试重点
  银行汇票

商业汇票的付款期限：最长不超过6个月
提示承兑期限：到期日前提示
提示付款期限：到期日起10日内
```

#### 票据行为（⭐⭐⭐核心）

```
出票：创设票据权利的行为
背书：票据权利的转让
承兑：付款人承诺到期付款
保证：第三人为票据债务提供担保

背书的规则（⭐⭐⭐必考）：
  ① 背书必须连续（前一手被背书人 = 后一手背书人）
  ② 背书不得附条件（附条件的，条件无效但背书有效）
  ③ 部分背书无效（不能只转让部分金额）
  ④ 背书人对后手承担担保付款责任

不得背书转让的情形：
  ① 出票人记载"不得转让"
  ② 背书人记载"不得转让"→ 仅对其直接后手以后的不承担保证责任
```

#### 票据抗辩

```
对物抗辩（可以对任何持票人主张）：
  票据无效、到期未至、超过付款提示期限等

对人抗辩（只能对特定持票人主张）：
  与持票人之间的直接原因关系（如合同纠纷）
  
⚠️ 票据抗辩切断：
  正当持票人（善意取得）不受前手之间对人抗辩的影响
  → 这就是票据的"无因性"
```

### 二、证券法律制度

#### 证券发行

```
注册制（2024年全面实行）：
  发行条件由法律规定
  审核机构只做形式审查（信息披露是否完整）
  不对发行人的投资价值做判断

IPO的基本条件（股份公司）：
  ① 具备健全且运行良好的组织机构
  ② 具有持续经营能力
  ③ 最近3年财务会计报告无虚假记载
  ④ 符合证监会规定的其他条件
```

#### 信息披露（⭐⭐重要）

```
持续信息披露：
  定期报告：年度报告（4个月内）、中期报告（2个月内）
  临时报告：发生重大事件时及时披露

重大事件（⭐需要临时披露的）：
  ① 重大诉讼、仲裁
  ② 公司重大投资或重大资产购置
  ③ 董事、1/3以上监事或经理发生变动
  ④ 持有5%以上股份的股东持股变动
  ⑤ 重大担保
  ⑥ 公司合并、分立、解散
```

#### 上市公司收购

```
要约收购 vs 协议收购：
  持股达到5% → 3日内报告并公告（举牌）
  每增减5% → 再次报告公告
  持股达到30% → 触发全面要约收购义务
  
  要约收购期限：30-60日
  收购期内：不得撤销要约
```

## 第七章 财政法律制度 ⭐⭐

> 🎯 分值：5-8分 | 题型：单选、多选、判断 | 难度：★★☆☆☆
> 近年趋势：预算法、政府采购方式、国有资产转让是选择题考点，难度不大。

### 一、预算法律制度

```
预算管理体制：
  一级政府 → 一级预算
  五级预算：中央 → 省 → 市 → 县 → 乡

预算审批权限：
  中央预算 → 全国人大审批
  地方预算 → 同级人大审批
  
  ⚠️ 人大常委会只能审批预算调整方案，不能审批预算本身

预算收入与支出：
  预算年度：1月1日 - 12月31日
  
  预算调整：
  需要增加举债数额 → 必须编制预算调整方案报人大常委会审批
  在执行中因上级专项转移支付增加 → 不属于预算调整
```

### 二、政府采购法律制度（⭐⭐）

#### 政府采购方式

| 方式 | 适用情形 | 特点 |
|:---|:---|:---|
| **公开招标** | 达到限额标准 | **主要方式**，竞争最充分 |
| 邀请招标 | 特殊性只有少数供应商 | 3家以上 |
| 竞争性谈判 | 招标后无合格标的 | 3家以上 |
| 竞争性磋商 | 技术复杂或性质特殊 | 3家以上 |
| 单一来源采购 | 只能从唯一供应商处采购 | 无竞争 |
| 询价 | 规格标准统一、现货 | 3家以上报价 |

```
💡 记忆口诀：
  公开招标 = 首选（钱多时用）
  单一来源 = 独家（没得选）
  其他都要 ≥ 3家参与

政府采购限额：
  公开招标限额标准：中央200万以上，地方各省规定
  
供应商质疑与投诉：
  质疑：向采购人提出（7个工作日内答复）
  投诉：对答复不满→向财政部门投诉（30个工作日内处理）
```

### 三、国有资产管理法律制度

```
企业国有资产转让：
  转让方式：公开进产权交易机构交易（原则上）
  
  审批权限：
  转让全部国有股权 → 同级人民政府批准
  转让部分国有股权（不丧失控股） → 同级国资委批准
  
  ⚠️ 国有资产评估：
  以下情形必须进行资产评估：
  ① 整体或部分改建为有限公司或股份公司
  ② 合并、分立、清算
  ③ 非上市公司国有股权转让
  ④ 资产转让、置换
  ⑤ 对外投资

行政事业性国有资产：
  配置 → 审批制（按标准配置）
  处置 → 审批制（不得擅自处置）
  出租出借 → 需要审批，收入上缴国库
```

### 📝 仿真题

**【单选】** 政府采购的主要方式是（ ）。
A. 邀请招标  B. 竞争性谈判  C. 公开招标  D. 单一来源采购

**答案：C** — 公开招标是政府采购的主要采购方式。

**【多选】** 下列情形中，应当对企业国有资产进行评估的有（ ）。
A. 整体改建为有限公司  B. 非上市公司国有股权转让
C. 对外投资  D. 日常经营活动中的一般采购

**答案：ABC** — D日常采购不需要资产评估。A、B、C都是法定必须评估的情形。

**【判断】** 地方各级预算由同级人民代表大会常务委员会审批。（ ）

**答案：×** — 预算由同级**人民代表大会**审批，不是常委会。常委会只审批预算调整方案。

## 第八章 相关法律制度 ⭐⭐

> 🎯 分值：5-10分 | 题型：单选、多选、判断 | 难度：★★★☆☆
> 近年趋势：增值税纳税人分类、税率、企业所得税扣除项目是选择题常客。

### 一、增值税法律制度

#### 纳税人分类

| | 一般纳税人 | 小规模纳税人 |
|:---|:---|:---|
| 标准 | 年应税销售额 > 500万 | ≤ 500万 |
| 计税方法 | 一般计税（进项抵扣） | 简易计税（征收率） |
| 税率 | 13%/9%/6% | 征收率3%（优惠1%） |
| 发票 | 可开专票 | 可代开/自开专票 |

#### 增值税税率（⭐⭐必背）

| 税率 | 适用范围 |
|:---|:---|
| **13%** | 销售货物、加工修理修配劳务、有形动产租赁 |
| **9%** | 交通运输、邮政、建筑、不动产租赁、销售不动产、转让土地使用权、农产品 |
| **6%** | 金融、现代服务、生活服务、销售无形资产（除土地） |
| **0%** | 出口货物、跨境应税行为 |

```
💡 记忆口诀：
  13% = 实物（看得见摸得着的货物）
  9% = 不动产 + 基础服务（建筑、交通、农产品）
  6% = 现代服务（金融、咨询、IT）
  0% = 出国的

一般计税：
  应纳税额 = 销项税额 - 进项税额
  销项税额 = 不含税销售额 × 税率

不得抵扣进项税额的情形（⭐必记）：
  ① 用于简易计税项目、免税项目
  ② 用于集体福利和个人消费
  ③ 非正常损失的购进货物
  ④ 购进的贷款服务、餐饮服务、居民日常服务、娱乐服务
```

### 二、企业所得税法律制度

#### 基本规定

```
纳税人：企业和其他取得收入的组织
  ⚠️ 个人独资企业和合伙企业不缴企业所得税（缴个人所得税）

税率：
  基本税率：25%
  小型微利企业：实际5%（应税所得 ≤ 300万）
  高新技术企业：15%
  非居民企业（无机构场所）：20%（实际10%）
```

#### 税前扣除标准（⭐⭐⭐高频考点）

| 项目 | 扣除标准 |
|:---|:---|
| **职工福利费** | 工资薪金总额的**14%** |
| **工会经费** | 工资薪金总额的**2%** |
| **职工教育经费** | 工资薪金总额的**8%**（超过部分结转以后年度） |
| **业务招待费** | 发生额的60%与营业收入5‰**孰低** |
| **广告宣传费** | 营业收入的**15%**（超过部分结转以后年度） |
| **公益性捐赠** | 年利润总额的**12%**（超过部分3年内结转） |

```
💡 业务招待费的双限额（⭐必考计算）：
  实际扣除 = min(发生额×60%, 营业收入×5‰)
  
  例：招待费100万，营业收入8000万
  限额1 = 100×60% = 60万
  限额2 = 8000×5‰ = 40万
  扣除 = min(60, 40) = 40万

不得扣除的项目：
  ① 向投资者支付的股息红利
  ② 企业所得税税款
  ③ 税收滞纳金
  ④ 罚金、罚款和被没收财物的损失
  ⑤ 赞助支出（非广告性质）
  ⑥ 未经核定的准备金支出
```

#### 税收优惠（⭐了解）

```
免税收入：
  ① 国债利息收入
  ② 符合条件的居民企业之间的股息红利
  ③ 符合条件的非营利组织收入

加计扣除：
  研发费用 → 加计100%扣除（即实际支出×200%扣除）
  残疾人工资 → 加计100%扣除
```

### 📝 仿真题

**【单选】** 下列各项中，增值税税率为9%的是（ ）。
A. 销售货物  B. 加工修理修配劳务  C. 交通运输服务  D. 金融服务

**答案：C** — 交通运输服务适用9%税率。A和B是13%，D是6%。

**【单选】** 企业发生业务招待费80万元，营业收入6000万元，可税前扣除的业务招待费为（ ）万元。
A. 80  B. 48  C. 30  D. 36

**答案：C** — 限额1=80×60%=48万；限额2=6000×5‰=30万；取孰低=**30万**。

**【多选】** 下列各项中，在计算企业所得税时不得扣除的有（ ）。
A. 税收滞纳金  B. 银行罚息  C. 被没收财物的损失  D. 公益性捐赠

**答案：AC** — A税收滞纳金和C被没收财物不得扣除。B银行罚息可以扣除（不是行政罚款）。D公益捐赠在限额内可扣除。

**【判断】** 个人独资企业应缴纳企业所得税。（ ）

**答案：×** — 个人独资企业和合伙企业不缴企业所得税，缴**个人所得税**。
