## 第一章 总论 ⭐

> 🎯 分值：2-3分 | 题型：单选、多选、判断 | 难度：★☆☆☆☆
> 近年趋势：每年必考1-2道客观题，主要考会计信息质量要求和计量属性。

### 一、会计基本假设

| 假设 | 核心含义 | 考试怎么考 |
|:---|:---|:---|
| **会计主体** | 界定核算的空间范围 | 会计主体≠法律主体（集团是会计主体但不是法律主体） |
| **持续经营** | 企业在可预见的未来不会破产清算 | 是采用历史成本计量、计提折旧的前提 |
| **会计分期** | 把持续经营期间切成一段段 | 是权责发生制、收付实现制的基础 |
| **货币计量** | 用货币作为统一尺子 | 记账本位币一般是人民币 |

> 💡 **大白话**：会计主体回答"给谁记账"，持续经营回答"能记多久"，会计分期回答"多久报一次"，货币计量回答"用什么记"。

### 二、会计信息质量要求（八项）

| 要求 | 一句话理解 | 典型案例 |
|:---|:---|:---|
| **可靠性** | 不做假账 | 最基本要求，是底线 |
| **相关性** | 信息要有用 | 能帮使用者做决策 |
| **可理解性** | 别写天书 | 报表要让人看得懂 |
| **可比性** | 横向纵向都能比 | 同行业用同一准则；自己前后期一致 |
| **实质重于形式** | 看本质不看外表 | 融资租赁虽然法律上没过户，但实质上是你的资产 |
| **重要性** | 大事单独说 | 金额大或性质特殊的要单独列报 |
| **谨慎性** | 做最坏打算 | 计提减值准备、确认或有负债 |
| **及时性** | 别拖 | 发生了就赶紧记 |

> ⚠️ **满分陷阱**：
> - 谨慎性 ≠ 可以随便多计提。不能设置秘密准备金！
> - "实质重于形式"是**最高频考点**，看到融资租赁、售后回购、附追索权的票据贴现就选它

### 三、会计要素与计量属性

**六大要素**：资产、负债、所有者权益（资产负债表）；收入、费用、利润（利润表）

**七种计量属性对照表**：

| 计量属性 | 什么意思 | 什么时候用 |
|:---|:---|:---|
| 历史成本 | 买的时候花了多少钱 | 存货、固定资产入账 |
| 重置成本 | 现在重新买要多少钱 | 盘盈固定资产 |
| 可变现净值 | 卖掉能收回多少钱 | 存货期末计量 |
| 现值 | 未来的钱折算到今天值多少 | 弃置费用、分期收款 |
| 公允价值 | 市场上公平交易的价格 | 交易性金融资产 |
| 净值 | 原价减去已折旧的 | 固定资产账面价值 |
| 名义金额 | 象征性记1块钱 | 无法可靠计量的政府补助资产 |

### 📝 仿真题

**【单选】** 下列各项中，体现实质重于形式要求的是（ ）。
A. 对存货计提跌价准备
B. 将融资租入固定资产视为自有资产核算
C. 合并财务报表的编制
D. 固定资产采用加速折旧法

**答案：B**
- A是谨慎性；B是实质重于形式（法律上没过户但实质控制）；C涉及会计主体；D是谨慎性/配比

**【判断】** 可比性要求企业采用的会计政策前后各期应当保持一致，不得变更。（ ）

**答案：×** — 可比性要求一贯性，但如果有更合理的政策，可以变更，只是需要披露说明。

## 第二章 存货 ⭐⭐

> 🎯 分值：3-5分 | 题型：单选、多选、判断、计算 | 难度：★★☆☆☆
> 近年趋势：期末计量（成本与可变现净值孰低）几乎年年考计算。

### 一、存货初始计量

**核心原则**：成本入账。不同来源，成本构成不同。

| 来源 | 成本 = | 特别注意 |
|:---|:---|:---|
| 外购 | 买价 + 运费 + 装卸费 + 保险费 + 入库前合理损耗 + 不可抵扣税 | **增值税一般纳税人的进项税不算** |
| 委托加工 | 材料成本 + 加工费 + 运费 + 消费税（看情况） | 消费税处理是必考点 |
| 自行生产 | 直接材料 + 直接人工 + 制造费用 | 非正常消耗不计入 |

**委托加工物资的消费税**（每年必考）：

| 收回后干什么 | 消费税怎么处理 | 为什么 |
|:---|:---|:---|
| 直接出售（售价 ≤ 计税价） | **计入成本** | 已纳税，售价不高于计税价无需再缴 |
| 继续加工应税消费品 | **记入"应交税费"借方**，可抵扣 | 避免重复征税 |
| 直接出售（售价 > 计税价） | **计入"税金及附加"** | 需补缴差额消费税 |

### 二、发出存货计量

| 方法 | 特点 | 物价上涨时 |
|:---|:---|:---|
| 先进先出法 | 先买的先走 | 利润偏高、期末存货接近市价 |
| 加权平均法 | 月末算一次平均单价 | 居中 |
| 移动加权平均法 | 每进一批货重算 | 更及时但计算量大 |
| 个别计价法 | 一一对应 | 适合贵重品 |

### 三、期末计量 · 成本与可变现净值孰低

**公式**：

```
期末存货价值 = min(成本, 可变现净值)

直接出售的存货：
  可变现净值 = 估计售价 - 估计销售费用 - 相关税费

需要加工的材料：
  可变现净值 = 产成品估计售价 - 至完工估计成本 - 估计销售费用 - 相关税费
```

> 🔥 **关键规则**：
> - 有销售合同的部分 → 用合同价算；无合同的部分 → 用市场价算；**分开算、分别比！**
> - 材料用于生产：产成品没跌价 → 材料就不跌价；产成品跌了 → 材料才要算跌价

### 📝 实战例题 · 可变现净值

**题目**：甲公司库存A产品100件，成本80万元。其中60件有合同，合同价0.9万元/件；40件无合同，市场价0.75万元/件。预计每件销售费用0.1万元。

**解题**：

```
有合同部分（60件）：
  成本 = 80 × 60/100 = 48万元
  可变现净值 = 60 × 0.9 - 60 × 0.1 = 54 - 6 = 48万元
  48 ≥ 48 → 不计提跌价准备

无合同部分（40件）：
  成本 = 80 × 40/100 = 32万元
  可变现净值 = 40 × 0.75 - 40 × 0.1 = 30 - 4 = 26万元
  32 > 26 → 需计提跌价准备 = 32 - 26 = 6万元

合计应计提存货跌价准备 = 0 + 6 = 6万元

借：资产减值损失    6
    贷：存货跌价准备  6
```

### 📝 仿真题

**【多选】** 下列各项中，应计入存货成本的有（ ）。
A. 存货加工过程中发生的正常损耗
B. 为特定客户设计产品发生的可直接确定的设计费用
C. 商品流通企业进货过程中发生的保险费
D. 生产过程中为达到下一个生产阶段所必需的仓储费用

**答案：ABCD** — 全部都计入。D容易错，注意是"必需的仓储费"不是一般仓储费。

## 第三章 固定资产 ⭐⭐

> 🎯 分值：5-8分 | 题型：全题型 | 难度：★★☆☆☆
> 近年趋势：折旧计算（尤其双倍余额递减法）、后续支出资本化/费用化、处置损益科目选择是高频考点。

### 一、初始计量

| 取得方式 | 入账成本 | 注意 |
|:---|:---|:---|
| 外购 | 买价 + 税费 + 达到可使用状态前的直接支出 | **员工培训费不计入！** |
| 自建 | 达到可使用状态前的全部必要支出 | 试运行收入/支出计入损益，不冲减成本 |
| 分期付款（超过正常信用条件） | **各期付款额的现值** | 差额记"未确认融资费用" |
| 存在弃置费用 | 成本中包含弃置费用的**现值** | 对应贷方记"预计负债" |

**分期付款购买分录**：
```
借：固定资产（现值）
    未确认融资费用（总价 - 现值）
    贷：长期应付款（总价）
```

**弃置费用分录**：
```
入账时：
借：固定资产（含弃置费用现值）
    贷：预计负债（弃置费用现值）
        银行存款（其余价款）

每期计提利息：
借：财务费用
    贷：预计负债
```

### 二、折旧（计算必考）

**四种方法**：

| 方法 | 公式 | 要点 |
|:---|:---|:---|
| 年限平均法 | (原价 - 残值) ÷ 年限 | 最简单 |
| 工作量法 | (原价 - 残值) ÷ 总工作量 × 当期量 | 按用量分摊 |
| **双倍余额递减法** | 期初净值 × 2/n | **前期不考虑残值**，最后2年改直线 |
| 年数总和法 | (原价 - 残值) × 尚可年限/年数总和 | 年数总和 = n(n+1)/2 |

### 📝 实战例题 · 双倍余额递减法

**题目**：设备原价100万元，预计使用5年，残值4万元。用双倍余额递减法计算各年折旧。

**解题**：
```
年折旧率 = 2/5 = 40%

第1年：100 × 40% = 40万     →  净值60
第2年：60 × 40%  = 24万     →  净值36
第3年：36 × 40%  = 14.4万   →  净值21.6
第4年：(21.6 - 4) ÷ 2 = 8.8万  ← 最后2年改直线法
第5年：(21.6 - 4) ÷ 2 = 8.8万

验证：40 + 24 + 14.4 + 8.8 + 8.8 = 96 = 100 - 4 ✓
```

### 三、后续支出

| 类型 | 标准 | 处理 |
|:---|:---|:---|
| **资本化** | 延长寿命、提升性能 | 先转在建工程，改良完再转回固定资产；替换部分账面价值转营业外支出 |
| **费用化** | 日常维修保养 | 管理费用或销售费用 |

### 四、处置

```
① 转入清理：
借：固定资产清理（账面价值）
    累计折旧
    固定资产减值准备
    贷：固定资产（原价）

② 清理净损益：
正常出售/转让 → 资产处置损益
报废/毁损     → 营业外支出 / 营业外收入
```

> ⚠️ **盘盈盘亏对比**（满分必记）：
> | | 存货盘盈 | 固定资产盘盈 |
> |:---|:---|:---|
> | 处理 | 冲减**管理费用** | **以前年度损益调整**（前期差错） |

### 📝 仿真题

**【单选】** 甲公司自行建造一条生产线，建造期间领用外购原材料成本50万元（已抵扣进项税），发生工程人员工资30万元。生产线达到预定可使用状态前进行试运行，取得试运行收入10万元、发生试运行成本6万元。该生产线入账价值为（ ）万元。
A. 76  B. 80  C. 86  D. 70

**答案：A**
- 入账价值 = 50 + 30 = 80万元。试运行收入10万和成本6万均计入当期损益（营业收入/营业成本），**不影响固定资产成本**。
- 等等，这里注意：根据最新准则（2023年修订），试运行期间的净收入不再冲减固定资产成本。但需看具体教材年份，2026年考试如按新规则则答案为80万元（选B）。
- **满分提示**：一定以当年教材为准！此处以最新准则回答 → **选B = 80万元**。

## 第四章 无形资产 ⭐⭐

> 🎯 分值：3-5分 | 题型：单选、多选、判断、计算 | 难度：★★☆☆☆
> 近年趋势：研发支出资本化条件是选择题必考，摊销科目也常考。

### 一、确认条件

三条件同时满足：可辨认性 + 经济利益很可能流入 + 成本可靠计量

> 💡 **商誉不是无形资产**！因为商誉不具有可辨认性（不能单独出售转让）。

### 二、研发支出（核心考点）

| 阶段 | 会计处理 | 大白话 |
|:---|:---|:---|
| **研究阶段** | 全部**费用化** → 管理费用 | "还在探索，不确定能不能成" |
| **开发阶段** | 满足5个条件的**资本化** → 无形资产 | "已经有眉目了，大概率能成" |

**开发阶段资本化5个条件**（缺一不可）：

> 🔥 **记忆口诀**：**技意用钱量**
> 1. **技**术上可行
> 2. 有完成并使用的**意**图
> 3. 能证明其有**用**性（能产生经济利益）
> 4. 有足够的**钱**（资源支持）
> 5. 支出能可靠计**量**

**分录**：
```
研究阶段支出：
借：研发支出—费用化支出
    贷：原材料/银行存款/应付职工薪酬
期末：
借：管理费用
    贷：研发支出—费用化支出

开发阶段支出（满足条件）：
借：研发支出—资本化支出
    贷：原材料/银行存款/应付职工薪酬
达到可使用状态：
借：无形资产
    贷：研发支出—资本化支出
```

### 三、后续计量

| 使用寿命 | 处理 |
|:---|:---|
| **有限** | 按寿命摊销（取合同期限、法律期限、经济寿命中的较短者） |
| **不确定** | **不摊销**，但每年末至少做一次减值测试 |

**摊销计入什么科目？**

| 用途 | 借方 |
|:---|:---|
| 自用（管理用） | 管理费用 |
| 自用（生产用） | 制造费用 |
| 出租 | 其他业务成本 |

### 四、处置

| 操作 | 性质 | 损益科目 |
|:---|:---|:---|
| **出售**（转让所有权） | 资产处置 | 资产处置损益 |
| **出租**（让渡使用权） | 日常经营 | 其他业务收入/其他业务成本 |

### 📝 实战例题 · 研发支出

**题目**：甲公司自行研发一项专利技术。2025年1-6月为研究阶段，发生支出200万元；7-11月为开发阶段，发生支出300万元（其中满足资本化条件的250万元）；12月1日达到可使用状态，预计使用10年。

**要求**：计算2025年的费用化金额、资本化金额和12月的摊销额。

```
费用化金额 = 200（研究阶段）+ 50（开发阶段不满足条件部分）= 250万元
资本化金额 = 250万元 → 记入无形资产

12月摊销额 = 250 ÷ 10 ÷ 12 = 2.08万元（当月起摊销）

2025年管理费用中包含：
- 研发支出费用化 250万
- 无形资产摊销 2.08万
```

> ⚠️ **满分陷阱**：无形资产摊销从**当月开始**（不像固定资产从下月开始折旧）！

### 📝 仿真题

**【判断】** 使用寿命不确定的无形资产不需要摊销，也不需要进行减值测试。（ ）

**答案：×** — 不摊销是对的，但**每年至少一次减值测试**！

**【单选】** 无形资产的摊销开始时间是（ ）。
A. 取得当月  B. 取得次月  C. 达到可使用状态当月  D. 达到可使用状态次月

**答案：C** — 无形资产**当月开始摊销、处置当月停止摊销**。正好和固定资产相反。

## 第五章 投资性房地产 ⭐⭐⭐

> 🎯 分值：5-8分 | 题型：全题型 | 难度：★★★☆☆
> 近年趋势：两种计量模式对比、转换处理（尤其公允价值模式下转入的差额处理）是综合题高频点。

### 一、范围界定

**投资性房地产 = 赚租金或等升值的房地产**

| ✅ 属于 | ❌ 不属于 |
|:---|:---|
| 已出租的土地使用权 | 自用房地产 |
| 持有并准备增值后转让的土地使用权 | 房地产企业的待售商品房（存货） |
| 已出租的建筑物 | 出租给自己员工住的宿舍 |

> 🔥 **必考判断题集锦**：
> - 出租给职工住 → ❌ 不是（属于自用）
> - 经营租赁租入再转租 → ❌ 不是（你不拥有它）
> - 出租给关联方 → ✅ 是（只看出租行为，不管对方是谁）

### 二、两种计量模式

| | 成本模式 | 公允价值模式 |
|:---|:---|:---|
| 折旧/摊销 | ✅ 要 | ❌ 不要 |
| 减值准备 | ✅ 要（不可转回） | ❌ 不要 |
| 公允价值变动 | 不涉及 | 计入公允价值变动损益 |
| 租金收入 | 其他业务收入 | 其他业务收入 |
| 模式转换 | 可以→公允 | **不可以→成本**（单向的！） |
| 采用条件 | 默认 | 有活跃市场+能持续取得公允价值 |

### 三、公允价值模式核心分录

```
取得：
借：投资性房地产—成本
    贷：银行存款

公允价值上升：
借：投资性房地产—公允价值变动
    贷：公允价值变动损益

公允价值下降：反向

取得租金：
借：银行存款
    贷：其他业务收入

处置时（两步走）：
① 借：银行存款
       贷：其他业务收入
   借：其他业务成本
       贷：投资性房地产—成本
                       —公允价值变动（可借可贷）
② 同时将累计公允价值变动转出：
   借：公允价值变动损益
       贷：其他业务成本（或反向）
```

### 四、转换（⭐⭐⭐最核心考点）

**自用/存货 → 投资性房地产（公允价值模式）**：

```
关键记忆："好事记OCI，坏事进损益"

公允价值 > 账面价值（升值）：
  差额 → 其他综合收益（OCI）  ← 谨慎性，好事不进利润表

公允价值 < 账面价值（贬值）：
  差额 → 公允价值变动损益     ← 坏消息立刻确认损失
```

**投资性房地产 → 自用/存货（公允价值模式）**：
- 以转换日公允价值作为新资产入账价值
- 差额全部计入 **公允价值变动损益**（不分好坏）

### 📝 实战例题

**题目**：甲公司将自用办公楼转为以公允价值模式计量的投资性房地产。原价2000万元，已提折旧400万元，未减值。转换日公允价值1800万元。

```
账面价值 = 2000 - 400 = 1600万元
公允价值 = 1800万元 > 1600万元 → 升值200万 → 计OCI

借：投资性房地产—成本    1800
    累计折旧             400
    贷：固定资产          2000
        其他综合收益       200
```

> 💡 如果公允价值 = 1500万（贬值100万）：
> ```
> 借：投资性房地产—成本    1500
>     累计折旧             400
>     公允价值变动损益       100    ← 坏事直接进损益
>     贷：固定资产          2000
> ```

### 📝 仿真题

**【多选】** 下列关于投资性房地产的说法中，正确的有（ ）。
A. 同一企业可以同时采用成本模式和公允价值模式
B. 已采用公允价值模式的不得转为成本模式
C. 成本模式转公允价值模式属于会计政策变更
D. 公允价值模式下也需要计提折旧

**答案：BC**
- A错，只能用一种；B对，单向不可逆；C对，属于政策变更用追溯调整法；D错，公允价值模式不折旧

## 第六章 长期股权投资与合营安排 ⭐⭐⭐

> 🎯 分值：10-15分 | 题型：全题型（综合题必出） | 难度：★★★★★
> 近年趋势：几乎**每年综合题**都会考本章。权益法调整净利润、核算方法转换是重中之重。
>
> ⚠️ 这是中级会计实务的"最终Boss"，吃透本章 = 拿下15分。

### 一、三种投资类型

| 类型 | 持股参考 | 影响力 | 后续计量 |
|:---|:---|:---|:---|
| 子公司 | 通常 > 50% | **控制** | **成本法** |
| 合营企业 | 通常 50% 共同控制 | **共同控制** | **权益法** |
| 联营企业 | 通常 20%-50% | **重大影响** | **权益法** |
| < 20%无影响力 | — | 无 | **不是长股投**，按金融资产 |

> 💡 **大白话**：
> - 控制 = "我说了算"
> - 共同控制 = "咱俩商量着来"
> - 重大影响 = "我说的你得听一听"
> - 比例只是参考，**实质判断才是核心**

### 二、初始计量（三种来源，三套规则）

#### ① 同一控制下企业合并（"一家人内部调整"）

```
初始成本 = 被合并方在最终控制方合并报表中的净资产账面价值 × 份额

特点：
- 按账面价值（不是公允价值）
- 不产生商誉
- 差额调整资本公积（不够就冲留存收益）
- 合并费用 → 管理费用
```

#### ② 非同一控制下企业合并（"外部收购"）

```
初始成本 = 付出对价的公允价值

特点：
- 按公允价值
- 成本 > 对方净资产公允份额 → 商誉（合并报表中体现）
- 成本 < 对方净资产公允份额 → 营业外收入（"占便宜了"）
- 合并费用 → 管理费用
```

#### ③ 非企业合并（"单纯买股票"）

```
初始成本 = 购买价款 + 直接相关费用（佣金、手续费等）
```

> 🔥 **同一vs非同一对比表**（满分必记）：

| | 同一控制 | 非同一控制 |
|:---|:---|:---|
| 本质 | 家族重组 | 市场收购 |
| 计量基础 | 账面价值 | 公允价值 |
| 商誉 | 无 | 可能有 |
| 差额 | 调资本公积 | 商誉或营业外收入 |

### 三、成本法（对子公司，简单）

**核心**：长股投账面价值基本不动。被投资方分红了才确认收益。

```
被投资方宣告分红：
借：应收股利
    贷：投资收益

收到：
借：银行存款
    贷：应收股利
```

> 💡 成本法就像"房东收租"——房子（账面价值）不变，收了租（分红）就是收入。

### 四、权益法（对联营/合营，核心！！）

**核心**：你的长股投账面价值**跟着对方净资产一起动**。

#### Step 1：初始成本调整

```
成本 ≥ 应享有的对方净资产公允价值份额 → 不调
成本 < 应享有的对方净资产公允价值份额 → 调增，差额记营业外收入

例：你花800万买了30%，对方净资产公允价值3000万
应享有份额 = 3000 × 30% = 900万
800 < 900 → 补记100万

借：长期股权投资—投资成本    100
    贷：营业外收入            100
```

#### Step 2：对方赚钱/亏钱 → 调损益

```
对方赚了→你也跟着记收益：
借：长期股权投资—损益调整
    贷：投资收益

对方亏了→你也跟着记亏损：
借：投资收益
    贷：长期股权投资—损益调整
```

> ⚠️ **但是！** 不能直接用对方的净利润，需要**调整后**再乘以持股比例。

#### Step 3：调整净利润（⭐⭐⭐必考三步曲）

**调整1 — 公允价值折旧/摊销差额**：
购买日对方资产的公允价值和账面价值有差异，要按公允价值重新算折旧/摊销。

**调整2 — 内部交易未实现损益**：
投资方和被投资方之间的买卖，尚未卖给外部第三方的利润要扣掉。

**调整3 — 会计政策统一**：
双方政策不一致时统一到投资方的政策。

```
调整后净利润 = 账面净利润
    - 公允价值比账面价值多摊销的折旧/摊销
    - 未实现的内部交易损益
    ± 会计政策调整

投资收益 = 调整后净利润 × 持股比例
```

#### Step 4：对方其他综合收益变动

```
借：长期股权投资—其他综合收益
    贷：其他综合收益
```

#### Step 5：对方分红

```
借：应收股利
    贷：长期股权投资—损益调整  ← 注意不是"投资收益"！
```

> 💡 权益法下分红是**冲减账面价值**而不是确认收益（因为赚钱时已经确认过了）。

### 📝 实战例题 · 权益法调整净利润（综合题必考）

**题目**：甲公司持有乙公司30%股权，权益法核算。2025年乙公司实现净利润1000万元。需调整事项：
1. 乙公司一项设备：账面600万，购买日公允800万，剩余10年，直线法，无残值
2. 甲公司向乙公司销售商品500万（成本400万），期末乙公司尚有50%未售出

**解题四步走**：

```
第1步：公允价值折旧调整
  额外折旧 = (800-600) ÷ 10 = 20万
  调减 20万

第2步：内部交易调整（甲→乙，顺流交易）
  未实现利润 = (500-400) × 50% = 50万
  调减 50万

第3步：计算调整后净利润
  1000 - 20 - 50 = 930万

第4步：确认投资收益
  930 × 30% = 279万

借：长期股权投资—损益调整    279
    贷：投资收益              279
```

### 五、核算方法转换

| 转换情况 | 典型场景 | 处理要点 |
|:---|:---|:---|
| 成本法 → 权益法 | 处置部分股权，丧失控制但保留重大影响 | 剩余部分追溯调整，视同从取得时就用权益法 |
| 权益法 → 成本法 | 追加投资取得控制 | 原投资 + 新投资合并为初始成本 |
| 成本法 → 金融资产 | 处置部分股权，丧失控制也无重大影响 | 剩余按公允价值重新计量，差额进损益 |
| 权益法 → 金融资产 | 处置部分股权，丧失重大影响 | 剩余按公允价值重新计量，差额进损益 |
| 金融资产 → 权益法 | 追加投资取得重大影响 | 原金融资产公允价值 + 新投入 = 初始成本 |
| 金融资产 → 成本法 | 追加投资取得控制 | 非同一控制下合并 |

> ⚠️ **满分陷阱**：成本法→权益法需要**追溯调整**，这是综合题高频出题点！

### 📝 仿真题

**【单选】** 甲公司以1200万元取得乙公司30%股权，能施加重大影响。取得时乙公司可辨认净资产公允价值4500万元。甲公司初始确认时应计入营业外收入的金额为（ ）万元。
A. 0  B. 150  C. 300  D. 1350

**答案：B**
```
应享有份额 = 4500 × 30% = 1350万
初始成本 = 1200万 < 1350万
差额 = 1350 - 1200 = 150万 → 营业外收入
```

**【判断】** 权益法下，被投资方宣告分派现金股利，投资方应贷记"投资收益"。（ ）

**答案：×** — 应贷记"长期股权投资—损益调整"。权益法下赚钱时已确认过收益，分红是**收回投资**。

## 第七章 资产减值 ⭐⭐

> 🎯 分值：5-8分 | 题型：单选、多选、判断、计算 | 难度：★★★☆☆
> 近年趋势：可收回金额的计算、资产组减值的分摊是计算题重点。

### 一、适用范围

本章资产减值准则适用于**长期资产**（一旦计提**不可转回**）：

| 适用本章（不可转回） | 不适用本章（另有规定） |
|:---|:---|
| 固定资产 | 存货（可转回） |
| 无形资产 | 金融资产（另有准则） |
| 长期股权投资 | 投资性房地产-公允模式（不计减值） |
| 商誉 | 递延所得税资产（另有准则） |
| 投资性房地产-成本模式 | — |

> 🔥 **满分必记**：哪些减值可以转回？
> - ✅ 可以转回：存货跌价准备、金融资产减值准备、合同资产减值
> - ❌ 不可转回：固定资产、无形资产、长期股权投资、商誉

### 二、可收回金额

```
可收回金额 = max(公允价值 - 处置费用, 预计未来现金流量现值)

哪个高用哪个（取大的那个和账面价值比）
如果可收回金额 < 账面价值 → 需要计提减值
```

**预计未来现金流量现值**注意事项：
- 以资产当前状况为基础，不考虑未来改良
- 不包括筹资活动和所得税现金流
- 折现率用税前利率

### 三、资产组减值（计算题重点）

**资产组**：能独立产生现金流入的最小资产组合。

**分摊步骤**：
```
第1步：确定资产组的可收回金额
第2步：比较账面价值，确定减值总额
第3步：分摊减值（按各资产账面价值比例），但注意限制条件：
  - 先冲商誉
  - 各资产分摊后的账面价值不得低于以下三者中最高的：
    ① 公允价值 - 处置费用
    ② 预计未来现金流量现值
    ③ 零
```

### 📝 实战例题 · 资产组减值分摊

**题目**：甲公司某资产组由设备A、设备B和一项专利权组成。总账面价值500万元，其中：A=200万、B=150万、专利=150万。可收回金额为350万元。设备A的公允价值-处置费用为180万元。

```
减值总额 = 500 - 350 = 150万元（无商誉）

按比例分摊：
  A应分摊：150 × 200/500 = 60万 → A减后 = 200-60 = 140万
  但A的公允-处置费 = 180万 > 140万
  所以A最多只能减值到180万 → A实际减 = 200-180 = 20万

  剩余应分摊 = 150 - 20 = 130万（在B和专利之间分）
  B应分摊：130 × 150/300 = 65万  → B减后 = 150-65 = 85万
  专利应分：130 × 150/300 = 65万  → 专利减后 = 150-65 = 85万

借：资产减值损失    150
    贷：固定资产减值准备—A    20
        固定资产减值准备—B    65
        无形资产减值准备       65
```

### 📝 仿真题

**【判断】** 固定资产减值损失一经确认，在以后会计期间不得转回。（ ）

**答案：✅** — 长期资产减值准则规定，减值损失一经确认不得转回。

**【单选】** 资产组减值分摊时，应首先冲减的是（ ）。
A. 固定资产  B. 无形资产  C. 商誉  D. 长期股权投资

**答案：C** — 有商誉的先冲商誉，剩余再按比例分摊到其他资产。

## 第八章 金融资产和金融负债 ⭐⭐⭐

> 🎯 分值：8-12分 | 题型：全题型 | 难度：★★★★☆
> 近年趋势：三分类的判断、公允价值变动的处理、重分类是高频考点。中级不要求新金融工具准则的全部深度，但三分类必须烂熟。

### 一、金融资产三分类

| 分类 | 简称 | 持有目的 | 计量基础 | 公允价值变动 |
|:---|:---|:---|:---|:---|
| 以摊余成本计量 | AC | 收取合同现金流量 | 摊余成本 | 不确认 |
| 以公允价值计量且其变动计入其他综合收益 | FVOCI | 收取现金流+出售 | 公允价值 | → 其他综合收益 |
| 以公允价值计量且其变动计入当期损益 | FVTPL | 其他（交易目的等） | 公允价值 | → 公允价值变动损益 |

**分类判断两步法**（业务模式 + 现金流特征）：

```
第1步：看业务模式
  - 仅为收取现金流 → AC
  - 收取现金流 + 出售 → FVOCI
  - 其他（交易、投机等） → FVTPL

第2步：看现金流特征（SPPI测试）
  - 仅为对本金和利息的支付 → 通过
  - 不通过 → 只能分为FVTPL
```

> 💡 **大白话**：
> - AC = "借钱给别人，只想安安稳稳收利息"（如债券持有到期）
> - FVOCI = "买了债券，可能收利息也可能中途卖"
> - FVTPL = "炒股、炒基金、做短线交易"

### 二、FVTPL（交易性金融资产）

```
购入（取得）：
借：交易性金融资产—成本（公允价值）
    投资收益（交易费用）              ← 费用化！
    应收股利/应收利息（已宣告但未发放的）
    贷：银行存款

持有期间公允价值上升：
借：交易性金融资产—公允价值变动
    贷：公允价值变动损益

持有期间确认利息/股利：
借：应收利息/应收股利
    贷：投资收益

出售：
借：银行存款
    贷：交易性金融资产—成本
                      —公允价值变动（可借可贷）
        投资收益（差额）
```

> ⚠️ **关键**：交易费用计入**投资收益（借方）**，不计入成本！

### 三、AC（债权投资，摊余成本计量）

```
购入：
借：债权投资—成本（面值）
            —利息调整（差额，可借可贷）
    应收利息（已到期未收的）
    贷：银行存款

期末计息（实际利率法）：
借：应收利息（面值 × 票面利率）
    贷：投资收益（期初摊余成本 × 实际利率）
        债权投资—利息调整（差额）

到期收回：
借：银行存款
    贷：债权投资—成本
```

**摊余成本公式**：
```
期末摊余成本 = 期初摊余成本 + 投资收益 - 现金流入 - 已收回本金 - 减值损失
            = 期初摊余成本 × (1 + 实际利率) - 票面利息
```

### 四、FVOCI（其他债权投资）

**兼具AC和FVTPL的特征**：
- 按公允价值计量（像FVTPL）
- 但公允价值变动计入OCI（不影响利润）
- 利息收入按实际利率法（像AC）
- 处置时将OCI累计额**转入投资收益**

### 📝 实战例题 · 交易性金融资产

**题目**：甲公司2025年1月1日以1050万元购入某公司股票100万股，其中包含已宣告但未发放的股利50万元。另支付交易费用5万元。2月1日收到股利。6月30日该股票公允价值为1100万元。9月30日以1200万元全部出售。

```
① 1月1日购入：
借：交易性金融资产—成本        1000（1050-50）
    应收股利                     50
    投资收益                      5（交易费用费用化）
    贷：银行存款                1055

② 2月1日收到股利：
借：银行存款    50
    贷：应收股利  50

③ 6月30日公允价值变动：
借：交易性金融资产—公允价值变动    100（1100-1000）
    贷：公允价值变动损益             100

④ 9月30日出售：
借：银行存款                      1200
    贷：交易性金融资产—成本        1000
        交易性金融资产—公允价值变动  100
        投资收益                    100

累计影响损益 = -5 + 100 + 100 = 195万元
```

### 📝 仿真题

**【单选】** 企业取得交易性金融资产时发生的交易费用，应当计入（ ）。
A. 管理费用  B. 交易性金融资产成本  C. 投资收益  D. 公允价值变动损益

**答案：C** — 借记投资收益（费用化处理）。

**【多选】** 下列金融资产中，应以公允价值计量的有（ ）。
A. 交易性金融资产
B. 债权投资
C. 其他债权投资
D. 其他权益工具投资

**答案：ACD** — B是债权投资，以摊余成本计量。其他三个都用公允价值。

## 第九章 职工薪酬 ⭐⭐

> 🎯 分值：3-5分 | 题型：单选、多选、判断 | 难度：★★☆☆☆
> 近年趋势：设定受益计划、非货币性福利、辞退福利是高频考点。

### 一、职工薪酬的分类

| 类型 | 内容 | 确认时点 |
|:---|:---|:---|
| **短期薪酬** | 工资、奖金、社保、公积金、工会经费、教育经费、非货币性福利 | 职工提供服务的期间 |
| **离职后福利** | 养老金（设定提存/设定受益）| 提供服务期间 |
| **辞退福利** | 解除劳动关系补偿 | 不能单方面撤回时 |
| **其他长期职工福利** | 长期带薪缺勤、长期利润分享 | 提供服务期间 |

### 二、短期薪酬核心处理

**非货币性福利**（高频考点）：

| 情形 | 会计处理 |
|:---|:---|
| 自产产品发给职工 | 视同销售，按公允价值确认收入并计提销项税 |
| 外购商品发给职工 | 进项税额转出（不视同销售，按成本） |
| 将自有房屋无偿提供给职工 | 按折旧额确认薪酬 |
| 租赁房屋给职工住 | 按租金确认薪酬 |

**自产产品发放分录**：
```
计提时：
借：生产成本/管理费用（公允价值 + 销项税）
    贷：应付职工薪酬

发放时：
借：应付职工薪酬
    贷：主营业务收入（公允价值）
        应交税费—应交增值税（销项税额）
同时结转成本：
借：主营业务成本
    贷：库存商品
```

### 三、辞退福利

```
确认条件：企业已制定正式的辞退计划且不能单方面撤回

借：管理费用（不是生产成本！）
    贷：应付职工薪酬

注意：辞退福利一律计入管理费用，不按受益对象分配！
```

### 📝 仿真题

**【判断】** 企业以自产产品作为非货币性福利发放给职工，应当按产品成本确认收入。（ ）

**答案：×** — 应按产品**公允价值（售价）**确认收入，按成本结转主营业务成本。

**【单选】** 辞退福利应计入（ ）。
A. 生产成本  B. 制造费用  C. 管理费用  D. 销售费用

**答案：C** — 辞退福利不论受益对象，**一律计入管理费用**。

## 第十章 股份支付 ⭐⭐

> 🎯 分值：3-5分 | 题型：单选、多选、判断、计算 | 难度：★★★☆☆
> 近年趋势：权益结算与现金结算的区分、等待期内费用确认是必考点。

### 一、两种股份支付

| | 权益结算的股份支付 | 现金结算的股份支付 |
|:---|:---|:---|
| **结算方式** | 给股票/股票期权 | 给现金（但金额和股价挂钩） |
| **计量基础** | 授予日公允价值（**锁定！**后续不调） | 每个资产负债表日公允价值（**持续更新**） |
| **贷方科目** | 资本公积—其他资本公积 | 应付职工薪酬 |
| **典型例子** | 股票期权激励 | 股票增值权 |

> 💡 **大白话**：
> - 权益结算 = "发股票"，股票给出去后价格涨跌跟公司无关 → 按授予日价格一锁到底
> - 现金结算 = "发现金但跟股价挂钩"，要付多少钱随股价变 → 每期更新公允价值

### 二、等待期内的会计处理

**权益结算**：
```
每期确认费用 = 授予日公允价值总额 × 期末累计可行权比例 ÷ 等待期年限 - 以前已确认金额

借：管理费用等
    贷：资本公积—其他资本公积
```

**现金结算**：
```
每期确认费用 = 资产负债表日公允价值 × 期末累计可行权比例 ÷ 等待期年限 - 以前已确认金额

借：管理费用等
    贷：应付职工薪酬
```

### 三、行权日

**权益结算行权**：
```
借：银行存款（行权价 × 股数）
    资本公积—其他资本公积（等待期累计）
    贷：股本（面值）
        资本公积—股本溢价（差额）
```

### 📝 实战例题

**题目**：甲公司2024年1月1日向100名管理人员每人授予1000份股票期权，等待期3年，授予日每份期权公允价值15元。预计2024年末有10人离职，2025年末累计有20人离职，2026年末实际有25人离职。

```
2024年应确认费用：
  (100-10) × 1000 × 15 × 1/3 = 450,000元
  借：管理费用  450,000
      贷：资本公积—其他资本公积  450,000

2025年应确认费用：
  (100-20) × 1000 × 15 × 2/3 - 450,000 = 800,000 - 450,000 = 350,000元
  借：管理费用  350,000
      贷：资本公积—其他资本公积  350,000

2026年应确认费用：
  (100-25) × 1000 × 15 × 3/3 - 800,000 = 1,125,000 - 800,000 = 325,000元
  借：管理费用  325,000
      贷：资本公积—其他资本公积  325,000
```

### 📝 仿真题

**【多选】** 下列关于股份支付的说法中，正确的有（ ）。
A. 权益结算以授予日公允价值计量，后续不再调整
B. 现金结算以每个资产负债表日公允价值重新计量
C. 股份支付的等待期内，每期费用按直线法分摊
D. 可行权日后，权益结算的股份支付不再确认成本费用

**答案：ABD** — C错误，不是简单的直线法分摊，需要考虑**可行权人数的最佳估计**，采用累计确认法。
