## 第十九章 租赁 ⭐⭐

> 🎯 分值：5-8分 | 题型：单选、多选、判断、计算 | 难度：★★★☆☆
> 近年趋势：新租赁准则下承租人的处理（使用权资产+租赁负债）是计算题重点。

### 一、租赁的识别

**租赁**：在一定期间内，出让方让渡资产使用权，承租人支付对价。

**核心判断**：合同是否包含租赁 → 看客户是否有权**控制已识别资产的使用**。

### 二、承租人的会计处理（重点！）

**新准则核心变化**：承租人不再区分经营租赁/融资租赁，所有租赁（除短期和低价值例外）统一确认**使用权资产**和**租赁负债**。

#### 初始计量

```
使用权资产 = 租赁负债初始金额 + 预付租金 + 初始直接费用 + 预计复原成本

租赁负债 = 尚未支付的租赁付款额的现值
  包括：固定付款额、实质固定付款额、购买选择权（合理确定行使）、
       终止罚金（合理确定行使终止选择权）

借：使用权资产
    租赁负债—未确认融资费用（差额）
    贷：租赁负债—租赁付款额（未支付总额）
        银行存款（预付款+初始直接费用）
        预计负债（复原成本现值）
```

#### 后续计量

```
使用权资产折旧：
借：管理费用/制造费用等
    贷：使用权资产累计折旧

租赁负债利息：
借：财务费用（期初租赁负债余额 × 折现率）
    贷：租赁负债—未确认融资费用

支付租金：
借：租赁负债—租赁付款额
    贷：银行存款
```

#### 短期租赁和低价值资产租赁（简化处理）

| 类型 | 条件 | 处理 |
|:---|:---|:---|
| 短期租赁 | 租赁期 ≤ 12个月且无购买选择权 | 直接费用化 |
| 低价值资产 | 全新状态下价值较低（如笔记本电脑） | 直接费用化 |

```
简化处理：
借：管理费用等
    贷：银行存款
```

### 三、出租人的会计处理

出租人**仍然区分**融资租赁和经营租赁：

| | 融资租赁 | 经营租赁 |
|:---|:---|:---|
| 本质 | 实质转移了资产风险报酬 | 未转移 |
| 出租人处理 | 终止确认资产，确认应收融资租赁款 | 保留资产，租金收入按直线法确认 |
| 承租人处理 | 统一模型（使用权资产+租赁负债） | 统一模型（同上） |

### 📝 实战例题

**题目**：甲公司2025年1月1日租入一间办公室，租期3年，每年末支付租金50万元，折现率5%。年金现值系数(P/A,5%,3)=2.7232。

```
租赁负债初始金额 = 50 × 2.7232 = 136.16万

借：使用权资产            136.16
    租赁负债—未确认融资费用  13.84（150-136.16）
    贷：租赁负债—租赁付款额   150（50×3）

第1年末：
  利息 = 136.16 × 5% = 6.81万
  借：财务费用    6.81
      贷：租赁负债—未确认融资费用  6.81
  
  支付租金：
  借：租赁负债—租赁付款额  50
      贷：银行存款          50

  折旧 = 136.16 ÷ 3 = 45.39万
  借：管理费用              45.39
      贷：使用权资产累计折旧  45.39
```

### 📝 仿真题

**【判断】** 新租赁准则下，承租人应将所有租赁均确认使用权资产和租赁负债。（ ）

**答案：×** — 短期租赁和低价值资产租赁可以选择简化处理，不确认使用权资产。

## 第二十章 持有待售的非流动资产、处置组和终止经营 ⭐

> 🎯 分值：2-3分 | 题型：单选、判断 | 难度：★★☆☆☆
> 近年趋势：分类条件和后续计量偶尔出1-2道客观题。

### 一、持有待售的分类条件

同时满足：
1. 可**立即出售**（当前状态下可按惯常条件出售）
2. 出售**极可能发生**（已获批准+已签协议+预计1年内完成）

### 二、后续计量

```
持有待售的非流动资产：
  按账面价值与公允价值减去出售费用后净额的孰低计量

  如果公允-出售费用 < 账面 → 减值
  借：资产减值损失
      贷：持有待售资产减值准备

  持有待售期间不折旧、不摊销！
```

### 三、终止经营

**定义**：已被处置或被划分为持有待售类别的、代表一项独立的主要业务或一个单独的主要经营地区的组成部分。

> 💡 终止经营需要在财务报表中**单独列报**。

### 📝 仿真题

**【判断】** 划分为持有待售类别的固定资产应继续计提折旧。（ ）

**答案：×** — 持有待售的非流动资产**停止折旧和摊销**。

## 第二十一章 企业合并与合并财务报表 ⭐⭐⭐

> 🎯 分值：10-15分 | 题型：全题型（综合题必出） | 难度：★★★★★
> 近年趋势：合并报表调整抵销分录是综合题"常客"，几乎年年出大题。
>
> ⚠️ 本章与第6章（长股投）并称"终极双Boss"，是中级实务最难、分值最高的两章。

### 一、企业合并的类型

| | 同一控制下合并 | 非同一控制下合并 |
|:---|:---|:---|
| 本质 | 家族内部重组 | 市场交易 |
| 计量 | 账面价值 | 公允价值 |
| 商誉 | 无 | 合并成本 > 可辨认净资产公允价值份额 |
| 合并日报表 | 视同一直合并（追溯重述） | 只从购买日起纳入 |

### 二、合并财务报表的编制（核心！）

**编制步骤**：
```
第1步：统一会计政策和会计期间
第2步：调整子公司个别报表（以公允价值为基础调整）→ 只在非同一控制下做
第3步：将母子公司报表数据简单合计
第4步：编制抵销分录
```

### 三、核心抵销分录（⭐⭐⭐必背）

#### ① 母公司长期股权投资与子公司所有者权益的抵销

```
借：股本（子公司）
    资本公积（子公司）
    盈余公积（子公司）
    未分配利润—年末（子公司）
    商誉（差额）
    贷：长期股权投资（母公司）
        少数股东权益（少数股东份额）
```

#### ② 母公司投资收益与子公司利润分配的抵销

```
借：投资收益（母享有的子公司净利润份额）
    少数股东损益（少数股东份额）
    未分配利润—年初（子公司上年末）
    贷：提取盈余公积（子公司当年提取）
        对所有者的分配（子公司当年分红）
        未分配利润—年末（子公司当年末）
```

#### ③ 内部交易的抵销

**内部存货交易**：
```
当期：
借：营业收入（内部销售收入）
    贷：营业成本（内部销售成本）
        存货（未实现利润 = 内部售价 - 内部成本）× 未售比例

连续编制（上年的未实现利润用未分配利润替代）：
借：未分配利润—年初
    贷：存货 / 营业成本
```

**内部固定资产交易**：
```
借：营业收入（内部售价）
    贷：营业成本（内部成本）
        固定资产—原价（未实现利润）

抵销多提的折旧：
借：固定资产—累计折旧
    贷：管理费用
```

**内部债权债务**：
```
借：应付账款（子公司）
    贷：应收账款（母公司）

借：应收账款—坏账准备
    贷：信用减值损失
```

### 四、非同一控制下的调整分录

购买日子公司资产账面价值 ≠ 公允价值时，需要调整：

```
以子公司固定资产为例（公允 > 账面）：
借：固定资产（公允-账面差额）
    贷：资本公积

后续每年补提折旧：
借：管理费用
    贷：固定资产—累计折旧
```

### 📝 实战例题 · 内部存货交易抵销

**题目**：母公司2025年向子公司销售商品1000万元（成本700万），子公司当年对外售出60%，剩余40%年末仍在库存。

```
未实现利润 = (1000-700) × 40% = 120万

抵销分录：
借：营业收入    1000
    贷：营业成本   880（1000-120）
        存货       120
```

> 💡 **理解**：合并报表里，母子公司是一个整体。内部买卖等于"左手倒右手"，收入成本全部抵掉，未卖出的部分利润从存货里扣掉。

### 📝 仿真题

**【单选】** 编制合并报表时，母公司对子公司的长期股权投资应与子公司的（ ）相互抵销。
A. 实收资本  B. 所有者权益  C. 净利润  D. 营业收入

**答案：B** — 母公司长期股权投资与子公司**所有者权益**对冲抵销。

**【判断】** 同一控制下企业合并，合并报表中应确认商誉。（ ）

**答案：×** — 同一控制下不产生商誉，差额调整资本公积。只有非同一控制下才可能产生商誉。

## 第二十二章 会计政策、会计估计变更和差错更正 ⭐⭐

> 🎯 分值：5-8分 | 题型：全题型 | 难度：★★★☆☆
> 近年趋势：区分政策变更与估计变更、追溯调整法的运用是计算题和综合题考点。

### 一、会计政策变更 vs 会计估计变更

| | 会计政策变更 | 会计估计变更 |
|:---|:---|:---|
| **定义** | 对同一交易采用了不同的**确认、计量、列报**方法 | 对**金额和时间**的估计发生变化 |
| **处理方法** | **追溯调整法** | **未来适用法** |
| **典型例子** | 投资性房地产成本→公允模式；存货计价方法变更 | 固定资产折旧年限变更、坏账比例调整 |
| **影响** | 调整期初留存收益 | 只影响当期及以后 |

> 🔥 **分不清的时候怎么办？**
> - 涉及**分类、确认标准、方法**改变 → 政策变更
> - 涉及**数字估算**改变 → 估计变更
> - 记忆：**新准则要求的变更 = 政策变更**

### 二、追溯调整法（会计政策变更）

```
步骤：
1. 计算变更的累积影响数
2. 调整期初留存收益和相关项目
3. 调整比较期间的财务报表
4. 附注披露

关键分录（调期初留存收益）：
借/贷：相关资产/负债
    贷/借：利润分配—未分配利润
           盈余公积
```

### 三、前期差错更正

| 差错类型 | 处理 |
|:---|:---|
| **不重要的前期差错** | 视同当期发现当期调整 |
| **重要的前期差错** | **追溯重述法**（与追溯调整类似） |

**重要前期差错核心分录**：
```
借/贷：相关科目
    贷/借：以前年度损益调整

然后：
借：以前年度损益调整
    贷：利润分配—未分配利润
借：利润分配—未分配利润
    贷：盈余公积（补提10%）
```

### 📝 实战例题

**题目**：甲公司2025年发现2024年漏记一笔固定资产折旧100万元（重要差错），税率25%。

```
补记折旧：
借：以前年度损益调整    100
    贷：累计折旧          100

调整所得税（可抵扣差异）：
借：递延所得税资产        25（100×25%）
    贷：以前年度损益调整    25

结转：
借：利润分配—未分配利润   75（100-25）
    贷：以前年度损益调整    75

补提盈余公积：
借：盈余公积              7.5（75×10%）
    贷：利润分配—未分配利润  7.5
```

### 📝 仿真题

**【单选】** 下列各项中，属于会计估计变更的是（ ）。
A. 将投资性房地产的计量模式从成本模式改为公允价值模式
B. 将固定资产的折旧年限从10年改为8年
C. 将坏账核算从直接转销法改为备抵法
D. 将存货的计价方法从先进先出法改为加权平均法

**答案：B** — B是金额估计（年限）的变更。A、C、D都是核算方法/政策的变更。

## 第二十三章 资产负债表日后事项 ⭐⭐

> 🎯 分值：5-8分 | 题型：单选、多选、判断、计算 | 难度：★★★☆☆
> 近年趋势：调整事项vs非调整事项的判断是高频选择题，调整事项的分录常结合其他章节出综合题。

### 一、日后期间

```
资产负债表日（12月31日）→ → → 财务报告批准报出日
                    ↑ 这段期间就是"日后期间" ↑
```

### 二、调整事项 vs 非调整事项

| 调整事项 | 非调整事项 |
|:---|:---|
| 日后期间获得**新证据**，证明资产负债表日已存在的状况 | 日后期间发生的**新情况** |
| **调整**报表数字 | **不调整**报表数字，只在附注中**披露** |

**常见调整事项**（⭐必记）：
1. 已确认资产减值的进一步证据（如诉讼判决）
2. 已售商品的退回
3. 资产负债表日后发现的报告期差错
4. 资产负债表日后发现的财务舞弊或差错

**常见非调整事项**：
1. 资产负债表日后发生的自然灾害
2. 股票/债券的发行
3. 资产负债表日后资产价格的重大变动
4. 资产负债表日后发生的企业合并或处置子公司
5. 资产负债表日后发生的重大诉讼

> 🔥 **判断口诀**：在12月31日那一天，这个事情**已经存在了吗**？
> - 已存在 → 调整事项（只是日后才知道）
> - 不存在 → 非调整事项（日后才发生的新事）

### 三、调整事项的处理

```
通过"以前年度损益调整"科目处理：

借/贷：相关科目
    贷/借：以前年度损益调整

然后结转到留存收益，并考虑所得税影响。
（处理方法与重要前期差错更正完全一致）
```

### 📝 实战例题

**题目**：甲公司12月31日为资产负债表日，2月15日为报告批准日。1月20日收到法院判决，需赔偿乙公司200万元（12月31日已确认预计负债150万）。

```
这是调整事项（诉讼在12月31日已存在，1月20日获得新证据）

需要调增预计负债 = 200 - 150 = 50万

借：以前年度损益调整    50
    贷：预计负债          50

调整所得税（假设税率25%）：
借：递延所得税资产        12.5
    贷：以前年度损益调整    12.5

结转：
借：利润分配—未分配利润   37.5
    贷：以前年度损益调整    37.5
```

### 📝 仿真题

**【多选】** 下列各项中，属于资产负债表日后调整事项的有（ ）。
A. 日后期间发现以前年度存在重大会计差错
B. 日后期间发生重大自然灾害导致资产毁损
C. 日后期间收到进一步证据表明应收账款无法收回
D. 日后期间董事会提出股票股利分配方案

**答案：AC**
- A是调整事项（差错在报告期已存在）；B是非调整事项（新事件）；C是调整事项（坏账在12月31日已存在）；D是非调整事项（新的分配决定）

## 第二十四章 政府会计 ⭐

> 🎯 分值：3-5分 | 题型：单选、多选、判断 | 难度：★★☆☆☆
> 近年趋势：政府会计的双基础、双报告体系是选择题考点。了解即可，不需要深入。

### 一、政府会计标准体系

**双基础**：

| | 预算会计 | 财务会计 |
|:---|:---|:---|
| **核算基础** | **收付实现制** | **权责发生制** |
| **目标** | 反映预算收支执行情况 | 反映财务状况和运行成本 |
| **要素** | 预算收入、预算支出、预算结余 | 资产、负债、净资产、收入、费用 |

**双报告**：
- **决算报告**：反映预算执行结果（收付实现制）
- **财务报告**：反映财务状况（权责发生制）

### 二、政府会计要素

| 财务会计（5个） | 预算会计（3个） |
|:---|:---|
| 资产、负债、净资产、收入、费用 | 预算收入、预算支出、预算结余 |

> 💡 政府会计没有"利润"，因为政府不以盈利为目的。用"净资产"代替"所有者权益"。

### 三、特殊资产——公共基础设施、政府储备物资、文物文化资产

| 资产类型 | 特点 |
|:---|:---|
| 公共基础设施 | 政府控制的公路、桥梁等，按成本计量 |
| 政府储备物资 | 战略储备物资，按成本计量 |
| 文物文化资产 | 无法可靠计量的不确认入账 |
| 保障性住房 | 属于政府的固定资产或存货 |

### 📝 仿真题

**【单选】** 政府预算会计的核算基础是（ ）。
A. 权责发生制  B. 收付实现制  C. 永续盘存制  D. 实地盘存制

**答案：B** — 预算会计用收付实现制，财务会计用权责发生制。

## 第二十五章 民间非营利组织会计 ⭐

> 🎯 分值：2-3分 | 题型：单选、判断 | 难度：★☆☆☆☆
> 近年趋势：偶尔出1道选择题，了解特有科目和净资产分类即可。

### 一、适用范围

社会团体、基金会、民办非企业单位、寺院、教堂等**不以营利为目的**的组织。

> ⚠️ 事业单位不适用本章，事业单位适用政府会计准则。

### 二、净资产分类（核心考点）

| 分类 | 含义 |
|:---|:---|
| **限定性净资产** | 捐赠人/授权人指定了用途或时间限制 |
| **非限定性净资产** | 没有使用限制，组织可自由支配 |

> 💡 企业用"所有者权益"，非营利组织用"净资产"，因为没有所有者。

### 三、特有业务

**受托代理业务**：
```
收到受托代理资产：
借：受托代理资产
    贷：受托代理负债

转交受益人：
借：受托代理负债
    贷：受托代理资产
```

**捐赠收入**：
```
接受捐赠（有限定）：
借：银行存款/固定资产等
    贷：捐赠收入—限定性收入

接受捐赠（无限定）：
借：银行存款/固定资产等
    贷：捐赠收入—非限定性收入

限定用途到期/完成时：
借：限定性净资产
    贷：非限定性净资产
```

### 📝 仿真题

**【判断】** 民间非营利组织的净资产分为限定性净资产和非限定性净资产。（ ）

**答案：✅** — 这是民间非营利组织净资产的两大分类。

**【单选】** 民间非营利组织接受捐赠人指定用途的捐赠，应确认为（ ）。
A. 非限定性收入  B. 限定性收入  C. 营业外收入  D. 其他收益

**答案：B** — 指定用途 = 有限定 → 限定性收入。
